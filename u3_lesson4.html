מה הופך בניין ל"כבד"?

בשיעור הקודם למדנו את שלושת הבניינים ה"קלים" — קל, נפעל ופיעל. בשיעור זה נלמד ארבעה בניינים נוספים הנחשבים "כבדים": פועל, התפעל, הפעיל, הופעל.

💡 כלל זהב — 7 בניינים ב-3 זוגות + 1: קל↔נפעל / פיעל↔פועל / הפעיל↔הופעל / התפעל (בודד). בכל זוג: אחד פעיל, השני סביל.

בניין פועל — הסביל של פיעל
פוע
בניין פועל — פֻּעַל
Pu'al — Passive of Pi'el
סבילקיבוץ בפ׳ + דגש בע׳זוג: פיעל↔פועל
משמעות: הסביל של פיעל. "דֻּבַּר" = דובר (ע"י מישהו). "לֻמַּד" = נלמד.
סימן מובהק: קיבוץ (ֻ) ישירות תחת פ׳ השורש + דגש חזק בע׳. שילוב ייחודי — לא קיים בשום בניין אחר.
הווה: מְפֻעָל — "מְדֻבָּר". עתיד: יְפֻעַל — "יְדֻבַּר".
דֻּבַּר · לֻמַּד · שֻׁבַּר · כֻּתַּב · זֻכַּר · גֻּדַּל
כל הזמנים בניין פועל — שורש ד-ב-ר
זמןעבר ג׳ ז"יהווה ז"יעתיד ג׳ ז"ישם פעולה
צורהדֻּבַּרמְדֻבָּריְדֻבַּר—
תבניתפֻּעַלמְפֻעָליְפֻעַל
נקבה י׳דֻּבְּרָהמְדֻבֶּרֶתתְּדֻבַּר—
⚠️ פועל נדיר בעברית מודרנית — אבל בבגרות חובה לזהות! הסימן הבלעדי: קיבוץ בפ׳ + דגש חזק בע׳ (ללא ה׳ קידומת). הבדלה מהופעל: הֻ (ה'+קיבוץ) = הופעל; קיבוץ ישירות בפ' = פועל.

3
בניין התפעל — חוזר-עצמי ועוד
התפ
בניין התפעל — הִתְפַּעֵל
Hitpa'el — Reflexive / Reciprocal
חוזר-עצמיקידומת הִתְ-הדדי / שינוי מצב
(1) חוזר-עצמי: "הִתְלַבֵּשׁ" = לבש את עצמו. "הִתְרַחֵץ" = רחץ את עצמו.
(2) הדדי: "הִתְכַּתְּבוּ" = כתבו זה לזה. "הִתְוַכְּחוּ" = ויכחו זה עם זה.
(3) שינוי מצב: "הִתְגַּדֵּל" = הפך לגדול. "הִתְחַמֵּם" = הפך לחם.
סימן מובהק: הִתְ- (עבר) · מִתְ- (הווה) · יִתְ- (עתיד).
⚠️ טרנספוזיציה: כשפ' השורש = ז/ד/ט/צ — הת' מתחלפת עם פ': "הִצְטַיֵּן" (לא "הִתְצַיֵּן"), "הִזְדַּקֵּן" (לא "הִתְזַקֵּן").
הִתְלַבֵּשׁ · הִתְכַּתֵּב · הִתְגַּדֵּל · הִצְטַיֵּן · הִזְדַּקֵּן
כל הזמנים בניין התפעל — שורש כ-ת-ב
זמןעבר ג׳ ז"יהווה ז"יעתיד ג׳ ז"ישם פעולה
צורההִתְכַּתֵּבמִתְכַּתֵּביִתְכַּתֵּבהִתְכַּתְּבוּת
תבניתהִתְפַּעֵלמִתְפַּעֵליִתְפַּעֵלהִתְפַּעֲלוּת
נקבה י׳הִתְכַּתְּבָהמִתְכַּתֶּבֶתתִּתְכַּתֵּבלְהִתְכַּתֵּב

בניין הפעיל — גורם לאחר לפעול
הפע
בניין הפעיל — הִפְעִיל
Hif'il — Causative Active
גרימההִ/מַ/יַ + חיריקזוג: הפעיל↔הופעל
משמעות — גרימה: "הִכְנִיס" = גרם להיכנס. "הִלְבִּישׁ" = גרם ללבוש. "הִשְׁמִיעַ" = גרם לשמוע.
משמעות — שינוי מצב: "הִגְדִּיל" = עשה לגדול. "הִכְשִׁיר" = עשה לכשיר.
סימנים: עבר = הִ + חיריק אחרי ל׳. הווה = מַ (פתח!) + חיריק. עתיד = יַ (פתח!) + חיריק.
שם פעולה: הַקְטָלָה — "הַכְנָסָה", "הַלְבָּשָׁה", "הַשְׁמָעָה".
הִכְנִיס · הִלְבִּישׁ · הִשְׁמִיעַ · הִגְדִּיל · הִכְשִׁיר · הֶחְלִיף
כל הזמנים בניין הפעיל — שורש כ-נ-ס
זמןעבר ג׳ ז"יהווה ז"יעתיד ג׳ ז"ישם פעולה
צורההִכְנִיסמַכְנִיסיַכְנִיסהַכְנָסָה
תבניתהִקְטִילמַקְטִיליַקְטִילהַקְטָלָה
נקבה י׳הִכְנִיסָהמַכְנִיסָהתַּכְנִיסלְהַכְנִיס
ז׳ רביםהִכְנִיסוּמַכְנִיסִיםיַכְנִיסוּ—
🔑 ניקוד יַ (פתח) בהפעיל-עתיד. שונה מקל (יִ חיריק) ומפיעל (יְ שוא). "יַכְנִיס" (הפעיל) ↔ "יִכְתֹּב" (קל) ↔ "יְדַבֵּר" (פיעל) ↔ "יֻכְנַס" (הופעל).

בניין הופעל — הסביל של הפעיל
הופ
בניין הופעל — הֻפְעַל
Huf'al — Passive of Hif'il
סבילקיבוץ בה׳ הקידומתזוג: הפעיל↔הופעל
משמעות: הסביל של הפעיל. "הֻכְנַס" = הוכנס. "הֻגְדַּל" = הוגדל. "הֻחְלַף" = הוחלף.
סימן בעבר: קידומת הֻ (ה׳ + קיבוץ) לפני פ׳ השורש.
סימן בהווה: קידומת מֻ — "מֻכְנָס". עתיד: יֻ — "יֻכְנַס".
הֻכְנַס · הֻגְדַּל · הֻחְלַף · הֻשְׁמַע · הֻלְבַּשׁ · הֻכְשַׁר
כל הזמנים בניין הופעל — שורש כ-נ-ס
זמןעבר ג׳ ז"יהווה ז"יעתיד ג׳ ז"י
צורההֻכְנַסמֻכְנָסיֻכְנַס
תבניתהֻקְטַלמֻקְטָליֻקְטַל
נקבה י׳הֻכְנְסָהמֻכְנֶסֶתתֻּכְנַס

טבלת זיהוי — כל 7 הבניינים
בנייןעבר ג׳ ז"יהווה ז"יעתיד ג׳ ז"יסימן מזהה עיקרי
קלכָּתַבכּוֹתֵביִכְתֹּבקמץ-פתח בעבר, חולם-צרה בהווה
נפעלנִכְתַּבנִכְתָּביִכָּתֵבנִ בעבר, דגש בפ׳ בשאר
פיעלכִּתֵּבמְכַתֵּביְכַתֵּבדגש חזק בע׳, יְ בעתיד
פועלכֻּתַּבמְכֻתָּביְכֻתַּבקיבוץ בפ׳ + דגש בע׳
התפעלהִתְכַּתֵּבמִתְכַּתֵּביִתְכַּתֵּבהִתְ / מִתְ / יִתְ לפני השורש

מפתח זיהוי מהיר — ראה קידומת → דע בניין
📋 ראה קידומת → זהה בניין
נִ +
נפעל-עבר. "נִכְתַּב" — נ לפני השורש = נפעל-עבר בלבד.
הִתְ +
התפעל-עבר. "הִתְכַּתֵּב" — הִתְ לפני פ' השורש = התפעל.
הִ + י
הפעיל-עבר. "הִכְנִיס" — הִ + חיריק אחרי ל' = הפעיל-עבר.
הֻ +
הופעל-עבר. "הֻכְנַס" — קיבוץ בה' = הופעל בלבד.
מַ + י
הפעיל-הווה. "מַכְנִיס" — מַ (פתח) + חיריק = הפעיל-הווה.
מֻ +
הופעל-הווה. "מֻכְנָס" — קיבוץ במ' = הופעל. (מְ + קיבוץ ישירות בפ' = פועל-הווה).
יַ +
הפעיל-עתיד. פתח בי' + חיריק = הפעיל. (יִ=קל/נפעל, יְ=פיעל, יַ=הפעיל, יֻ=הופעל).
