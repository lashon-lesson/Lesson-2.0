גזרת השלמים — בניינים כבדים

פועל, התפעל, הפעיל, הופעל — ארבעת הבניינים הכבדים: צורות, זמנים וסימנים מזהים. סיכום כל 7 הבניינים.

🤔 שאלת פתיחה

שתי שאלות: מה ההבדל בין הִגְדִּיל ל-הֻגְדַּל? ומה ההבדל בין הִתְגַּדֵּל ל-הִגְדִּיל?

כולן מאותו שורש ג-ד-ל — אבל כל אחת בבניין שונה. קראו את השיעור ואז ענו.

מה הופך בניין ל"כבד"?

בשיעור הקודם למדנו את שלושת הבניינים ה"קלים" — קל, נפעל ופיעל. בשיעור זה: ארבעת הבניינים ה"כבדים" — פועל, התפעל, הפעיל, הופעל.

💡 כלל הזהב — 7 בניינים ב-3 זוגות + 1:
קל ↔ נפעל (בסיסי / סביל)  |  פיעל ↔ פועל (מחוזק / סביל)  |  הפעיל ↔ הופעל (גרימה / סביל)  |  התפעל (חוזר-עצמי, בודד)

בניין פועל — הסביל של פיעל
פוע
בניין פועל — פֻּעַל / Pu'al
Passive of Pi'el — סביל של פיעל
סבילקיבוץ בפ׳ + דגש בע׳זוג: פיעל↔פועל
משמעות: הסביל של פיעל. "דֻּבַּר" = דובר ע"י מישהו. "לֻמַּד" = נלמד. "שֻׁבַּר" = שובר לרסיסים.
סימן בלעדי: קיבוץ (ֻ) ישירות תחת פ׳ השורש + דגש חזק בע׳. שילוב ייחודי — לא קיים בשום בניין אחר.
הווה: מְפֻעָל (מְדֻבָּר). עתיד: יְפֻעַל (יְדֻבַּר). שם פעולה: נדיר.
דֻּבַּר · לֻמַּד · שֻׁבַּר · כֻּתַּב · זֻכַּר · גֻּדַּל
כל הזמנים פועל — ד-ב-ר
זמןעבר ג׳ ז"יהווה ז"יעתיד ג׳ ז"י
צורהדֻּבַּרמְדֻבָּריְדֻבַּר
תבניתפֻּעַלמְפֻעָליְפֻעַל
נקבה י׳דֻּבְּרָהמְדֻבֶּרֶתתְּדֻבַּר
⚠️ פועל ↔ הופעל — מלכודת! שניהם קיבוץ, אבל: פועל = קיבוץ ישירות בפ׳ השורש (דֻּ — ד = פ׳). הופעל = קיבוץ בה׳ הקידומת (הֻ — ה = קידומת, לא שורש). "דֻּבַּר" = פועל. "הֻלְבַּשׁ" = הופעל.

3
בניין התפעל — חוזר-עצמי ועוד
התפ
בניין התפעל — הִתְפַּעֵל / Hitpa'el
Reflexive / Reciprocal / Change of State
חוזר-עצמיקידומת הִתְ-הדדי / שינוי מצב
(1) חוזר-עצמי: "הִתְלַבֵּשׁ" = לבש את עצמו. "הִתְרַחֵץ" = רחץ את עצמו.
(2) הדדי: "הִתְכַּתְּבוּ" = כתבו זה לזה. "הִתְוַכְּחוּ" = ויכחו זה עם זה.
(3) שינוי מצב: "הִתְגַּדֵּל" = הפך לגדול. "הִתְחַמֵּם" = הפך לחם.
סימן מובהק: עבר = הִתְ- · הווה = מִתְ- · עתיד = יִתְ-.
⚠️ טרנספוזיציה: כשפ׳ = ז/ד/ט/צ — הת׳ מתחלפת עם פ׳: "הִצְטַיֵּן" (←הִתְ+צ). "הִזְדַּקֵּן" (←הִתְ+ז).
הִתְלַבֵּשׁ · הִתְכַּתֵּב · הִתְגַּדֵּל · הִצְטַיֵּן · הִזְדַּקֵּן · הִתְרַחֵץ
כל הזמנים התפעל — כ-ת-ב
זמןעבר ג׳ ז"יהווה ז"יעתיד ג׳ ז"ישם פעולה
צורההִתְכַּתֵּבמִתְכַּתֵּביִתְכַּתֵּבהִתְכַּתְּבוּת
תבניתהִתְפַּעֵלמִתְפַּעֵליִתְפַּעֵלהִתְפַּעֲלוּת
נקבה י׳הִתְכַּתְּבָהמִתְכַּתֶּבֶתתִּתְכַּתֵּבלְהִתְכַּתֵּב

בניין הפעיל — גורם לאחר לפעול
הפע
בניין הפעיל — הִפְעִיל / Hif'il
Causative Active — גרימה
גרימההִ/מַ/יַ + חיריקזוג: הפעיל↔הופעל
משמעות — גרימה: "הִכְנִיס" = גרם להיכנס. "הִלְבִּישׁ" = גרם ללבוש. "הִשְׁמִיעַ" = גרם לשמוע.
משמעות — שינוי מצב: "הִגְדִּיל" = עשה לגדול. "הִכְשִׁיר" = עשה לכשיר.
סימן: עבר = הִ + חיריק אחרי ל׳. הווה = מַ (פתח!). עתיד = יַ (פתח!). הפתח = סימן מבדיל מפיעל (שוא) ומקל (חיריק).
שם פעולה: הַקְטָלָה — "הַכְנָסָה", "הַלְבָּשָׁה", "הַשְׁמָעָה".
הִכְנִיס · הִלְבִּישׁ · הִשְׁמִיעַ · הִגְדִּיל · הִכְשִׁיר · הֶחְלִיף
כל הזמנים הפעיל — כ-נ-ס
זמןעבר ג׳ ז"יהווה ז"יעתיד ג׳ ז"ישם פעולה
צורההִכְנִיסמַכְנִיסיַכְנִיסהַכְנָסָה
תבניתהִקְטִילמַקְטִיליַקְטִילהַקְטָלָה
נקבה י׳הִכְנִיסָהמַכְנִיסָהתַּכְנִיסלְהַכְנִיס
ז׳ רביםהִכְנִיסוּמַכְנִיסִיםיַכְנִיסוּ—
🔑 מַ/יַ (פתח) = סימן הפעיל בהווה/עתיד. שונה מ: קל (יִ חיריק) / פיעל (יְ שוא) / הופעל (יֻ קיבוץ). "יַכְנִיס" = הפעיל. "יִכְתֹּב" = קל. "יְדַבֵּר" = פיעל. "יֻכְנַס" = הופעל.

בניין הופעל — הסביל של הפעיל
הופ
בניין הופעל — הֻפְעַל / Huf'al
Passive of Hif'il — סביל של הפעיל
סבילהֻ / מֻ / יֻזוג: הפעיל↔הופעל
משמעות: הסביל של הפעיל. "הֻכְנַס" = הוכנס. "הֻגְדַּל" = הוגדל. "הֻלְבַּשׁ" = הולבש.
סימן בעבר: הֻ (ה׳ + קיבוץ) לפני פ׳ השורש. לא קיבוץ בפ׳ עצמה (= פועל)!
הווה: מֻ (קיבוץ במ׳) — "מֻכְנָס". עתיד: יֻ (קיבוץ ביו׳) — "יֻכְנַס".
הֻכְנַס · הֻגְדַּל · הֻחְלַף · הֻשְׁמַע · הֻלְבַּשׁ · הֻכְשַׁר
כל הזמנים הופעל — כ-נ-ס
זמןעבר ג׳ ז"יהווה ז"יעתיד ג׳ ז"י
צורההֻכְנַסמֻכְנָסיֻכְנַס
תבניתהֻקְטַלמֻקְטָליֻקְטַל

מפתח קידומות — קרא קידומת → זהה בניין
📋 ראה קידומת → זהה בניין מיידית
נִ +
נפעל-עבר בלבד. "נִכְתַּב" — נ לפני השורש = נפעל-עבר.
הִתְ +
התפעל-עבר. "הִתְכַּתֵּב" — הִתְ לפני פ׳ = התפעל. (+ טרנספוזיציה: הִצְטַיֵּן, הִזְדַּקֵּן)
הִ + חיריק
הפעיל-עבר. "הִכְנִיס" — הִ + חיריק אחרי ל׳ = הפעיל.
הֻ +
הופעל-עבר. "הֻכְנַס" — קיבוץ בה׳ = הופעל. (לא קיבוץ בפ׳ = לא פועל!)
מַ + חיריק
הפעיל-הווה. "מַכְנִיס" — מַ (פתח) + חיריק = הפעיל-הווה בלבד.
מֻ +
הופעל-הווה. "מֻכְנָס" — קיבוץ במ׳ = הופעל. (מְ + קיבוץ בפ׳ = פועל-הווה)
יַ + חיריק
הפעיל-עתיד. יַ (פתח!) = הפעיל. כלל עתיד: יִ=קל/נפעל | יְ=פיעל/פועל | יַ=הפעיל | יֻ=הופעל

שאלה 2: מה הניקוד הייחודי לקידומות הפעיל בהווה ועתיד (מַ/יַ) מול פיעל (מְ/יְ)?

טקסט א׳ — בניינים כבדים: פועל, התפעל, הפעיל, הופעל (שאלות 1–7)

הספר דֻּבַּר בשיעור. הילד הֻלְבַּשׁ בבוקר. המורה הִכְנִיסָה את התלמידים. הם הִתְכַּתְּבוּ שנים. הכלי מֻכְנָס לתוך הקופסה. הוא יַגְדִּיל את הטקסט.

📍 לכל פועל: זיהוי בניין, זמן, גוף, שורש.

טקסט ב׳ — זוגות פעיל–סביל (שאלות 8–14)

המורה לִמֵּד — הנושא לֻמַּד. הוא הִלְבִּישׁ — הילד הֻלְבַּשׁ. הם הִגְדִּילוּ את התמונה — התמונה הֻגְדְּלָה. הוא מִתְרַחֵץ מדי יום.

📍 זהו זוגות פעיל-סביל ואת הבניין המדויק של כל פועל.
