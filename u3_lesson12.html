שורשים תניינים וגזורי שם

בדרך כלל שם עצם נגזר מפועל. אבל לפעמים זה הפוך — פועל נגזר משם עצם! זהו "שורש תניין" — שורש שנולד משם. "גזור השם" הוא שם שנגזר משם אחר. שני מנגנונים שמרחיבים את השפה בכל יום.

⏱ 45 דק׳ 🔗 שורשים תניינים ⭐ שיעור אחרון 📝 לקראת מבחן
🤔 שאלת פתיחה

שני פעלים: לְבַיֵּת ו-לְמַלֵּחַ. מה שורשיהם?

התשובה מפתיעה — שניהם שורשים שנוצרו משמות עצם! קראו את השיעור ואז הסבירו: מאיזה שם כל אחד נגזר.

🔍
1
החידה — שמות שהפכו לשורשים

בדרך כלל: שורש → פועל → שם עצם. "כ-ת-ב" → "כָּתַב" → "כְּתִיבָה". אבל לפעמים הכיוון הפוך: שם קדם, ומתוכו נוצר שורש חדש שיצר פועל. זהו שורש תניין.

🔍 שישה שמות שהפכו לשורשים — שש הפתעות
בַּיִת
→
בִּיֵּת
ב-י-ת → בִּיֵּת (פיעל): לבייֵּת = להרגיל לבית, לאלף. "בייתו כלב רחוב". שורש מ"בית".
פיעל
מֶלַח
→
מִלֵּחַ
מ-ל-ח → מִלֵּחַ (פיעל): להמליח = להוסיף מלח. "מִלֵּחַ את הבשר". "מֶלַח" קדם.
פיעל
אוֹר
→
הֵאִיר
א-ו-ר → הֵאִיר (הפעיל): להאיר = לתת אור. "הֵאִיר את הכיתה". "אוֹר" קדם.
הפעיל
שֵׁן
→
שִׁנֵּן
שׁ-נ-נ → שִׁנֵּן (פיעל): לחדד/לחזור שוב ושוב (כמו שן חדה). "שינן את החומר".
פיעל
לֵב
→
הִתְלַבֵּב
ל-ב-ב → הִתְלַבֵּב (התפעל): להתמלא רגש. "הקהל הִתְלַבֵּב". מ"לֵב".
התפעל
אֶבֶן
→
הִתְאַבֵּן
א-ב-נ → הִתְאַבֵּן (התפעל): להתקשח כאבן, לקפוא. "הִתְאַבְּנוּ מהצער". מ"אֶבֶן".
התפעל
🔗 הגדרה — שורש תניין: שורש שנגזר משם עצם (ולא מפועל קדמון). "תניין" = שני/מאוחר — הפועל הוא המשני, בא אחרי השם. דוגמאות: ב-י-ת (מ"בית"), מ-ל-ח (מ"מלח"), א-ו-ר (מ"אור"), שׁ-נ-נ (מ"שן").
📖
2
כיצד לזהות שורש תניין — ארבעה מבחנים
📌 ארבעת מבחני הזיהוי
1. הפועל "נשמע" כמו שם עצם
2. יש שם עצם נפוץ במאגר
3. הפועל מביע פעולה הקשורה לשם
4. לרוב בפיעל, הפעיל או התפעל
בדיקה: "מה קדם — השם או הפועל?"
📌 שורשים תניינים נפוצים
שׂ-מ-ח ← שִׂמֵּחַ (מ"שִׂמְחָה")
ד-ב-שׁ ← דִּבֵּשׁ (מ"דְּבַשׁ")
מ-ל-ח ← מִלֵּחַ (מ"מֶלַח")
ע-ק-ב ← עִקֵּב (מ"עָקֵב")
כ-ת-ר ← כִּתֵּר (מ"כֶּתֶר")
מ-ל-כ ← מִלֵּךְ (מ"מֶלֶךְ")
📊
3
ארבע קטגוריות — מה מביע כל שורש תניין
לעשות עם השם
פעולה הקשורה לחומר/חפץ
הפועל מביע שימוש בחפץ הנקרא בשם.
מִלֵּחַ (מֶלַח) = להמליח דִּבֵּשׁ (דְּבַשׁ) = להוסיף דבש כִּתֵּר (כֶּתֶר) = להקיף ככתר
לקבל תכונת השם
מצב — להיות כמו השם
הנושא מקבל תכונה שמגולמת בשם.
בִּיֵּת (בַּיִת) = להפוך לביתי שִׁנֵּן (שֵׁן) = לחדד, לחזור שוב הִתְלַבֵּב (לֵב) = להתמלא רגש
לגרום לשם
גרמתי — לגרום לאחר לקבל
הפועל גרמתי: גורם לדבר אחר לקבל את תכונת השם.
הֵאִיר (אוֹר) = לגרום לאור מְאַדֵּם (אָדֹם) = לגרום להאדמה מְיַבֵּשׁ (יַבָּשׁ) = לגרום ליובש
להפוך לשם
להיות/להפוך כמו השם
הנושא עובר תהליך ונהיה כמו שם העצם.
הִתְיַתֵּם (יָתוֹם) = להיות ליתום הִתְאַלְמֵן (אַלְמוֹן) = להתאלמן הִתְאַבֵּן (אֶבֶן) = להתקשח
🌿
4
גזורי שם — שמות שנגזרו משמות אחרים

גזור שם = שם עצם שנגזר משם עצם אחר (לא משורש פועל). שם A → שם B. שני מנגנונים: הוספת צורן, או שינוי משקל. הבחינה: "מאיזה שם עצם זה נגזר?"

📊 שמות שנגזרו משמות — שמונה דוגמאות
שם המקורגזור השםמה הוסף / מה השתנה
יָםיַמִּי / יַמָּאיסיומת -י/-אי (שייכות)
עִירעִירוֹנִי / עֲיָרָהסיומת -וני / שינוי משקל
אֶרֶץאַרְצִי / אַרְצִיּוּת-י (שייכות) + -ות (הפשטה)
מֶלֶךְמַלְכוּת / מַמְלָכָה-ות (מצב) / משקל מַמְפָּעָה
חֶסֶדחַסִּיד / חֲסִידוּתמשקל קַטִּיל / + -ות
חָכְמָהחָכָם / חַכְמוֹןבעל תכונה / הקטנה
כֶּסֶףכַּסְפִּי / כַּסְפִּיָּה-י / -יה (שם מקום)
נֶפֶשׁנַפְשִׁי / נַפְשִׁיּוּת-י (שייכות) + -ות
🌿 כלל מרכזי: "מאיזה שם עצם זה נגזר?" — תשובה ברורה → גזור שם. "יַמִּי" ← "יָם". "מַלְכוּת" ← "מֶלֶךְ". "חַסִּיד" ← "חֶסֶד". הנגזר מבטא שייכות, תכונה, מקום או מצב הקשורים לשם האב.
⚖️
5
שורש תניין לעומת גזור שם — ההבדל המהותי
⚙️ שורש תניין — תוצאה: פועל
כיוון: שם → פועל
"מֶלַח" → מִלֵּחַ (פיעל)
"אוֹר" → הֵאִיר (הפעיל)
"לֵב" → הִתְלַבֵּב (התפעל)
כלל: התוצאה = פועל
📦 גזור שם — תוצאה: שם
כיוון: שם → שם אחר
"מֶלֶךְ" → מַלְכוּת (שם)
"יָם" → יַמִּי (שם תואר)
"חֶסֶד" → חַסִּיד (שם)
כלל: התוצאה = שם
🚨 שאלת הבחינה: "האם התוצאה פועל או שם?"

שורש תניין: "בַּיִת" → "בִּיֵּת" = פועל ← שורש תניין. גזור שם: "בַּיִת" → "בֵּיתִי" = שם תואר ← גזור שם. אותו שם מקור, שני כיוונים שונים. הכיוון = מה שקובע.

🏗️
6
שורשים תניינים בכל הבניינים
📊 שורשים תניינים לפי בניין
בנייןשכיחותקטגוריה נפוצהדוגמה
פיעלהנפוץ ביותרלעשות עם/בצורת השםמִלֵּחַ, דִּבֵּשׁ, כִּתֵּר, שִׁנֵּן
הפעילשכיחגרמתי — לגרום לתכונת השםהֵאִיר, הִנְגִּישׁ (מ"נָגִישׁ"), הֶחֱלִים
התפעלשכיחלהפוך להיות כמו השםהִתְיַתֵּם, הִתְאַלְמֵן, הִתְאַבֵּן
קלנדירמצב הקשור לשםצָם (מ"צוֹם"), אָדַם, שָׂח
💡 טיפ לבגרות: כשפועל "נשמע" כמו שם עצם — ובדרך כלל פיעל/הפעיל/התפעל — שאלו: "האם יש שם עצם מוכר במאגר?" אם כן → שורש תניין. "לְגַגֵּל", "לְפַקְסֵס", "לְאַיְמֵל" — שורשים תניינים מחיי הטכנולוגיה.
🔗 קישור לשיעור 8 — כשהשורש התניין "שובר" כלל של גזרה: השורש נ-ג-שׁ הוא חסר פ״נ, ולכן בהפעיל הנ"ון נבלעת: הִגִּישׁ / הַגָּשָׁה. אבל הפועל הִנְגִּישׁ ("להנגיש מבנה") נגזר מהשם נָגִישׁ ולא ישירות מהשורש — ולכן הוא שורש תניין שנוטה כשלמים ושומר על הנ"ון: הַנְגָּשָׁה. זה כלל רחב: שורש תניין מתנהג לפי הבסיס שממנו נגזר, ולא בהכרח לפי הגזרה ההיסטורית.
🗺️
7
מפת חזרה — כל 12 שיעורי יחידה 3
📚 12 שיעורים — מה למדנו ביחידה 3?
1
שיעור 1 — מבוא לתורת ההגה
מפתח: עיצורים, תנועות, שוואים, דגשים — הבסיס הפונולוגי
2
שיעור 2 — מבוא למערכת הצורות
מפתח: צורן, גזירה, נסייה — שורש ותבנית, כלי הניתוח הבסיסיים
3
שיעור 3 — גזרת השלמים: בניינים קלים
מפתח: קל, נפעל, פיעל — עבר/הווה/עתיד/ציווי בגזרת השלמים
4
שיעור 4 — גזרת השלמים: בניינים כבדים
מפתח: פועל, התפעל, הפעיל, הופעל — שבעת הבניינים שלמים
5
שיעור 5 — משמעויות הבניינים
מפתח: קל=פעיל. נפעל=סביל/חוזר. פיעל=עוצמה. הפעיל=גרמתי. התפעל=חוזר/הדדי/עמיד
6
שיעור 6 — שמות הפעולה
מפתח: פְּעִילָה (קל) · הִפָּעֲלוּת (נפעל) · פִּעּוּל (פיעל) · הַפְעָלָה (הפעיל) · הִתְפַּעֲלוּת (התפעל)
7
שיעור 7 — צורות הבינוני
מפתח: פועל (קוֹטֵל) ≠ פעול (קָטוּל). שלושה תפקידים. מלכודת: הסכמת ידיעה!
8
שיעור 8 — מרובעים וחסרי פ"נ
מפתח: מרובעים = 4 עיצורים, שם פעולה פִּעְלוּל. חפ"נ = נ׳ נבלעת בעתיד/ציווי (דגש)
9
שיעור 9 — חסרי פי"צ ונחי ל"א
מפתח: חפ"צ = גרונית ראשונה → חטף/הֶאֱ. נחי ל"א = א׳ שקטה → קמץ לפניה
10
שיעור 10 — נחי ל"י/ה
מפתח: י׳ מוסווית כה׳. לפני -וּ: נשמטת. לפני -ים/-תָּ/-נוּ: חוזרת. עתיד: -נֶה. ציווי: -נֵה
11
שיעור 11 — דרכי תצורת השם
מפתח: שורש+משקל (לא-לינארי) · בסיס+צורן (לינארי) · הלחמה (שני בסיסים)
12
שיעור 12 — שורשים תניינים וגזורי שם
מפתח: שורש תניין = שם → פועל. גזור שם = שם → שם. הכיוון קובע!
🛠️
8
5 שאלות לזיהוי + ברכה לקראת המבחן
🛠️ 5 שאלות לזיהוי שורש תניין וגזור שם
1
הפועל נשמע כמו שם? "בִּיֵּת", "מִלֵּחַ", "כִּתֵּר" — מזכירים שמות → שורש תניין.
2
יש שם עצם נפוץ באותם עיצורים? כ-ת-ר = "כֶּתֶר". מ-ל-ח = "מֶלַח". → שורש תניין.
3
הפועל קשור לאותו שם? "מִלֵּחַ" = פעולה עם מלח. → שורש תניין מקטגוריית "לעשות עם השם".
4
התוצאה היא שם (לא פועל)? "יָם" → "יַמִּי" = שם תואר → גזור שם (לא שורש תניין).
5
שאלת הבקרה: "מה קדם — השם או הפועל?" שם קדם → שורש תניין / גזור שם.
🏆 בהצלחה במבחן! סיימתם את כל 12 שיעורי יחידה 3 — ממשמעויות הבניינים דרך הגזרות ועד לתצורת המילה. שאלות המבחן: מה השורש? מה המשקל? מה הגזרה? מה הבניין? מה התצורה? כל הכלים בידיכם!
✅ שאלות מנחות לפני התרגול
שאלה 1: מה ההבדל בין "מִלֵּחַ" (שורש תניין) ל-"מַלְכוּת" (גזור שם)?
שאלה 2: "הִתְאַבֵּן" — לאיזו קטגוריה שייך? מאיזה שם? מה הבניין?
שאלה 3: "לְגַגֵּל" — האם זה שורש תניין? מדוע? מאיזה שם?

טקסט א׳ — עולם הטכנולוגיה (שאלות 1–7)

המחשב הנייד הפך לכלי-עבודה עיקרי. המפתח הצעיר עבד על תוכנה חדשה לניהול מסמכים. המערכת הבין-לאומית תומכת בריבוי שפות — כל משתמש יכול לבחור שפת-ממשק נוחה לו.

📍 לכל מילה מודגשת: זיהוי דרך תצורה (שורש+משקל / בסיס+צורן / הלחמה).

טקסט ב׳ — בית-הספר + ספורט (שאלות 8–14)

המחנך הותיק עמד מול כיתת-לימוד מלאה. הוא לא-ידוע ברחוב אך מפורסם בבית-הספר. "אחריות המחנך היא תת-הכרתית." הכדורגלן בחשמלית חשב על אימון — הכרטיסייה שלו מלאה ניקובים.
