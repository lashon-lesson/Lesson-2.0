שורשים תניינים וגזורי שם

בדרך כלל שם עצם נגזר מפועל. אבל לפעמים זה הפוך — פועל נגזר משם עצם! ה"שורש התניין" הוא שורש שנוצר מהשם, ו"גזור השם" הוא שם שנגזר משם אחר. שני התהליכים חיוניים להרחבת הלשון העברית

1
החידה — מאיפה בא "לְבַיֵּת"?

בדרך כלל אנחנו לומדים: שורש → פועל → שם עצם. "כ-ת-ב" → "כָּתַב" → "כְּתִיבָה". אבל מה עם הפועל לְבַיֵּת? איזה שורש יש לו?

התשובה מפתיעה: השורש הוא ב-י-ת — שנגזר משם העצם "בַּיִת". כלומר: השם קדם לפועל, לא ההפך! זהו "שורש תניין" — שורש שנולד משם עצם קיים.

🔍 שמות שהפכו לשורשים — שש דוגמאות מפתיעות
בַּיִת
→
בִּיֵּת
ב-י-ת → בִּיֵּת (פיעל): לבייֵּת = להפוך לביתי, לאלף, להרגיל לבית. "בייתו כלב רחוב". שורש שנולד מהשם "בית".
פיעל
אוֹר
→
הֶאִיר
א-ו-ר → הֵאִיר (הפעיל): להאיר = לתת אור. "השמש הֵאִירָה את הכיתה". "אור" קדם להפעיל.
הפעיל
שֵׁן
→
שִׁנֵּן
שׁ-נ-נ → שִׁנֵּן (פיעל): לשנן = לחדד, לחזור שוב ושוב (כמו שן שחודה). "שינן את החומר לפני המבחן".
פיעל
לֵב
→
הִתְלַבֵּב
ל-ב-ב → הִתְלַבֵּב (התפעל): להתלבב = להתמלא התלהבות ורגש. "הקהל הִתְלַבֵּב לשמע הבשורה". מ"לב".
התפעל
מַיִם
→
הִמִּים
מ-ו-מ/מ-י-מ → הִמִּים (הפעיל): להמים = להוסיף מים, לדלל. "הִמִּים את המיץ". שורש נולד מ"מים".
הפעיל
יָד
→
הִצְבִּיעַ
אצבע → הִצְבִּיעַ (הפעיל): להצביע = לכוון אצבע. "הִצְבִּיעַ על הבחירה". "אצבע" ← "הצביע".
הפעיל
🔗 הגדרה — שורש תניין: שורש שנגזר משם עצם (ולא מפועל קדמון). "תניין" = מאוחר יותר, שני. הפועל הוא המשני — הוא בא אחרי השם. דוגמאות: ב-י-ת (מ"בית"), א-ו-ר (מ"אור"), ש-נ-נ (מ"שן"), ל-ב-ב (מ"לב").
📖
2
שורשים תניינים — הגדרה, מאפיינים וזיהוי

שורש תניין (Denominative Root) הוא שורש שמקורו בשם עצם, ולא בשורש עצמאי קדום. בעברית, כשנדרשת מילה חדשה לפעולה הקשורה לחפץ, אדם או מושג — לעתים נוצר שורש חדש מ"הגוף" של שם העצם.

זה שונה מ"שורש ומשקל" רגיל שבו השורש קדום ושמות עצם נגזרים ממנו. כאן הכיוון הפוך: שם → שורש → פועל → מילים נוספות.

📌 כיצד לזהות שורש תניין
1. הפועל "נשמע" כמו שם עצם
2. יש שם עצם נפוץ במאגר
3. הפועל מביע פעולה הקשורה לאותו שם
4. לרוב בבניין פיעל, הפעיל, התפעל
בדיקה: "מה קודם — השם או הפועל?"
📌 שורשים תניינים נפוצים
שׂ-מ-חׂ ← שִׂמֵּחַ (מ"שִׂמְחָה")
ד-ב-שׁ ← דִּבֵּשׁ (מ"דְּבַשׁ")
מ-ל-ח ← מִלֵּחַ (מ"מֶלַח")
ע-ק-ב ← עִקֵּב (מ"עָקֵב")
כ-ת-ר ← כִּתֵּר (מ"כֶּתֶר")
ע-נ-ן ← עִנֵּן (מ"עָנָן")
📊
3
ארבע קטגוריות — מה מביע כל שורש תניין
פעולה הקשורה לשם
לעשות את מה שקשור לשם
הפועל מבטא פעולה שמשתמשת בחפץ הנקרא בשם.
מִלֵּחַ (מ"מֶלַח") = להמליח דִּבֵּשׁ (מ"דְּבַשׁ") = להוסיף דבש שׁוֹטֵר (מ"שּׁוֹטֵר") = לפקח
להיות כמו השם
לקבל תכונת השם
הפועל מבטא מצב של קבלת התכונה המגולמת בשם.
בִּיֵּת (מ"בַּיִת") = להפוך לביתי הִתְאַבֵּן (מ"אֶבֶן") = להתקשות כאבן הִתְפַּחֵם (מ"פֶּחָם") = להשחיר
לגרום לשם
לגרום לדבר להיות/לקבל
הפועל גרמתי — גורם למשהו לקבל את תכונת השם.
הֶאִיר (מ"אוֹר") = לגרום לאור הִשְׁלִים (מ"שָׁלֵם") = לעשות שלם הֶחֱלִים (מ"חֹלֶה") = לגרום להחלמה
להפוך לשם
להפוך להיות כמו השם
הנושא עובר שינוי ונהיה כמו/כן שם העצם.
הִתְיַתֵּם (מ"יָתוֹם") = להיות ליתום הִתְאַלְמֵן (מ"אַלְמוֹן") = להתאלמן הִתְלַבֵּב (מ"לֵב") = להתמלא לב
🌿
4
גזורי שם — שמות שנגזרו משמות אחרים

גזור שם הוא שם עצם שנגזר משם עצם אחר (ולא משורש פועל ישירות). כלומר: שם A → שם B. שני המנגנונים העיקריים: הוספת צורן, או שינוי משקל.

הבחינה: האם ניתן לאתר שם עצם "אבא" ממנו נגזר השם החדש?

שם המקור (אב) גזור השם (הנגזר) מה התוסף / מה השתנה
יָם (מים, ים)יַמִּי / יַמָּאיסיומת -י/-אי (שייכות לים)
עִיר (עיר)עִירוֹנִי / עֲיָרָהסיומת -וני / שינוי משקל
אֶרֶץ (ארץ)אֶרְצִי / אַרְצִיּוּתסיומת -י + -ות (הפשטה)
נֶפֶשׁ (נפש)נַפְשִׁי / נַפְשִׁיּוּתסיומת -י = שייך לנפש
מֶלֶךְ (מלך)מַלְכוּת / מַמְלָכָהמשקל מַפְעָלָה / -ות
חֶסֶד (חסד)חַסִּיד / חֲסִידוּתמשקל קַטִּיל + -ות
חָכְמָה (חכמה)חָכָם / חַכְמוֹןבעל תכונה / הקטנה
כֶּסֶף (כסף)כַּסְפִּי / כַּסְפִּיָּהסיומת -י / -יה (גוף מים)
🌿 כלל מרכזי — גזור שם: כשניתן לשאול "מאיזה שם עצם זה נגזר?" — ולקבל תשובה ברורה — מדובר בגזור שם. "יַמִּי" ← "יָם". "מַלְכוּת" ← "מֶלֶךְ". "חַסִּיד" ← "חֶסֶד". בדרך כלל הנגזר מבטא שייכות, תכונה, מקום, מקצוע הקשורים לשם האב.
⚖️
5
שורש תניין לעומת גזור שם — ההבדל המהותי

נקודת הבלבול הנפוצה: מה ההבדל בין "שורש תניין" לבין "גזור שם"?

  • שורש תניין = שם עצם → פועל. "בַּיִת" → "בִּיֵּת" (לבייֵּת). התוצאה היא פועל.
  • גזור שם = שם עצם → שם עצם אחר. "מֶלֶךְ" → "מַלְכוּת". התוצאה היא שם עצם (לא פועל).

שניהם תהליכים של גזירה משם — אך לתוצאות שונות: שורש תניין נותן פועל; גזור שם נותן שם עצם.

⚙️ שורש תניין — תוצאה: פועל
"מֶלַח" (שם) → שׁ+ר+ת: מִלֵּחַ (פיעל)
"אוֹר" (שם) → הֵאִיר (הפעיל)
"לֵב" (שם) → הִתְלַבֵּב (התפעל)
הכיוון: שם → פועל
📦 גזור שם — תוצאה: שם
"מֶלֶךְ" (שם) → מַלְכוּת (שם)
"יָם" (שם) → יַמִּי (שם תואר)
"חֶסֶד" (שם) → חַסִּיד (שם)
הכיוון: שם → שם (אחר)
🏗️
6
שורשים תניינים — בכל הבניינים

שורשים תניינים יכולים להופיע בכל הבניינים, אך יש נטייה ברורה:

  • פיעל — הנפוץ ביותר: "בִּיֵּת", "מִלֵּחַ", "דִּבֵּשׁ", "כִּתֵּר", "שִׁנֵּן". לרוב: לעשות דבר הקשור לשם.
  • הפעיל — גרמתי: "הֵאִיר" (מ"אור"), "הִמִּים" (מ"מים"), "הֶחֱלִים" (מ"חולה").
  • התפעל — הפיכה/מצב: "הִתְיַתֵּם" (מ"יתום"), "הִתְאַלְמֵן" (מ"אלמן"), "הִתְאַבֵּן" (מ"אבן").
  • קל — נדיר יחסית: "צָם" (מ"צוֹם"), "שָׁת" (מ"שֵׁת" = יסד), "אָדַם" (אדם).
🗺️

מפת הדרכים — חזרה על כל יחידה 3 לפני המבחן

5
שיעור 5 — משמעויות הבניינים
מפתח: קל (פעיל), נפעל (סביל/חוזר), פיעל (עוצמה/גרמתי), פועל, הפעיל (גרמתי ישיר), הופעל, התפעל (חוזר/הדדי/עמיד)
6
שיעור 6 — שמות הפעולה
מפתח: פְּעִילָה (קל), הִפָּעֲלוּת (נפעל), פִּעּוּל (פיעל), הַפְעָלָה (הפעיל), הִתְפַּעֲלוּת (התפעל)
7
שיעור 7 — צורות הבינוני
מפתח: בינוני פועל (קוֹטֵל) ≠ בינוני פעול (קָטוּל). שלושה תפקידים: פועל/שם/תואר. הסכמה בידיעה!
8
שיעור 8 — מרובעים וחסרי פ"נ
מפתח: מרובעים = 4 עיצורים, נוטה כפיעל, שם פעולה פִּעְלוּל. חפ"נ = נ׳ נבלעת בעתיד/ציווי
9
שיעור 9 — חסרי פי"צ ונחי ל"א
מפתח: חפ"צ = גרונית ראשונה → חטף/הֶאֱ. נחי ל"א = א׳ שקטה סופית → קמץ לפניה
10
שיעור 10 — נחי ל"י/ה
מפתח: י׳ מוסווית כה׳. לפני -וּ: נשמטת. לפני -ים/-תָ/-נוּ: חוזרת. עתיד: -נֶה. ציווי: -נֵה
11
שיעור 11 — דרכי תצורת השם
מפתח: שלוש דרכים: שורש+משקל (לא-לינארי), בסיס+צורן (לינארי), הלחמת בסיסים (שתי מילים)
12
שיעור 12 — שורשים תניינים וגזורי שם
מפתח: שורש תניין = שם → פועל. גזור שם = שם → שם. ההבדל: תוצאה פועל מול תוצאה שם
🛠️
8
כלי זיהוי — ואיחולים לקראת המבחן
🛠️ 5 שאלות לזיהוי שורש תניין וגזור שם
1
האם זה פועל שנשמע כמו שם? "בִּיֵּת", "מִלֵּחַ", "כִּתֵּר" — נשמעים כמו שמות → שורש תניין.
2
האם יש שם עצם מוכר שמתחיל באותם עיצורים? "כ-ת-ר" = "כֶּתֶר". "מ-ל-ח" = "מֶלַח". → שורש תניין.
3
האם הפועל מבטא קשר לאותו שם? "מִלֵּחַ" = לעשות מלח. "כִּתֵּר" = להעניק כתר. → כן, שורש תניין.
4
האם התוצאה היא שם (לא פועל)? "יָם" → "יַמִּי" (שם תואר). → גזור שם (לא שורש תניין).
5
שאלת הבקרה: מה קדם — השם או הפועל? אם השם קדם → שורש תניין / גזור שם. אם הפועל קדם → גזירה רגילה.

טקסט א׳ — המסעדה

הטבח מִלֵּחַ את הבשר ודִּבֵּשׁ את הירקות. השף כִּתֵּר את המנה בעשבי תיבול. "אני מְאַדֵּם כאן את העגבנייה," הסביר. "זה מְיַבֵּשׁ אותה ומרכז את הטעמים."

טקסט ב׳ — החיים משתנים

הזוג הִתְיַתֵּם בצעירותו והִתְאַלְמֵן בהמשך. אך הם לא הִתְאַבְּנוּ. "אנחנו מִתְלַבְּבִים מחדש," אמרו. "הלב לא מְאֻבֵּן לעולם." היַמִּיּוּת שבנפשם — האהבה לים ולאופקים — הֵאִירָה להם את הדרך.

טקסט ג׳ — מחקר לשוני

החוקר עִקֵּב אחר התפתחות השפה. "כיצד מַלְכוּת הפכה לתחום מחקר?" תהה. "מחַסִּידוּת נגזרה חֲסִידִיּוּת. מאַרְצִיּוּת נבנתה עֲיָרָה." הוא שִׁנֵּן לתלמידיו: "כל שם עצם מְאוֹצֵר בתוכו שורש חדש."
