גזרות — מרובעים וחסרי פ״נ

רוב הפעלים = גזרת שלמים. אך כשעיצור מיוחד בשורש, הפועל "נסטה" מהתבנית הרגילה. שיעור זה: מרובעים (4 עיצורים) וחסרי פ״נ (נ"ון ראשונה).

⏱ 45 דק׳ 🔷 גזרות 🎯 יחידה 3 שיעור 8
🤔 שאלת פתיחה

שני פעלים: כָּתַב (גזרת שלמים) מול נָפַל (חסרי פ״נ).

עתיד קל: יִכְתֹּב — אבל לא "יִנְפֹּל"! הצורה הנכונה היא יִפֹּל. מה קרה לנ"ון? ולמה יש דגש בפ"א? קראו את השיעור.

גזרת מרובעים — שורש בן 4 עיצורים
🔳 מרובעים — ארבעה עיצורים, נטייה כפיעל
הגדרה: שורש בן ארבעה עיצורים (במקום שלושה). הנטייה זהה לבניין פיעל בכל הצורות.
זיהוי: שם הפעולה = פִּעְלוּל (תִּרְגּוּם, גִּלְגּוּל) במקום פִּעּוּל (לִמּוּד, כִּבּוּס). העיצור הנוסף גלוי.
סוגים: כפול (ג-ל-ג-ל), מוארך (צ-ח-ק-ק), עצמאי (ת-ר-ג-מ), מושם (שׁ-ע-ב-ד).
מרובעים נטייה — ת-ר-ג-מ לעומת שלמים כ-ת-ב

🔷 כלל מרובעים: הנטייה זהה לפיעל. ההבדל היחיד: שם הפעולה = פִּעְלוּל (עיצור נוסף לפני וּ). תִּרְגּוּם, גִּלְגּוּל, דִּפְדּוּף, שִׁעְמּוּם.

גזרת חסרי פ״נ — הנ״ון שנבלעת
💥 חסרי פ״נ — פ׳ השורש = נ; נבלעת בעתיד ובציווי
הגדרה: שורשים שהאות הראשונה (פ׳) היא נ"ון. בצורות עתיד וציווי, הנ"ון נבלעת.
מנגנון: הטמעה (Assimilation) — נ׳ לפני עיצור ← נ׳ נמזגת לעיצור ← דגש חזק בעיצור שאחריה.
היכן נבלעת: עתיד קל (יִפֹּל) + ציווי (פֹּל) + הפעיל (הִפִּיל).
היכן נשמרת: עבר (נָפַל) + הווה (נוֹפֵל) + שם פעולה (נְפִילָה) + שם פועל (לִנְפֹּל).

⚠️ מלכודת — זיהוי שורש בהפעיל-חפ״נ

"הִגִּישׁ" — שורש נ-ג-שׁ, לא ג-ג-שׁ ולא ג-ש-שׁ! הדגש בג׳ = נ"ון נבלעה. "הִפִּיל" — שורש נ-פ-ל, לא פ-פ-ל. הראייה: שם הפעולה הַגָּשָׁה (גש!) / הַפָּלָה (פל!) — הנ"ון נעדרת.

5 שאלות לזיהוי גזרה
🛠️ 5 שאלות לזיהוי גזרה
1
ספרו עיצורי שורש: 4 עיצורים → מרובעים. 3 עיצורים → שלמים או חפ״נ.
2
פ׳ השורש = נ"ון? כן → חסרי פ״נ. בדקו עתיד: יִ + עיצור מדוגש בלי נ׳ = חפ״נ.
3
דגש חזק בפ׳ בעתיד? "יִפֹּל" — פּ׳ מדוגשת ← חפ״נ. "יִכְתֹּב" — כ׳ לא מדוגשת ← שלמים.
4
שם הפעולה מסתיים ב-וּ+ל+עיצור? תִּרְגּוּם, גִּלְגּוּל = מרובעים. לִמּוּד = שלמים-פיעל.
5
ציווי קצר מדי? "פֹּל" / "תֵּן" (2 עיצורים) ← חפ״נ. "כְּתֹב" (3) ← שלמים.

טקסט א׳ — מסע תרגום (שאלות 1–7)

המתרגם תִּרְגֵּם את הרומן במשך שנה שלמה. הוא גִּלְגֵּל כל משפט בראשו, דִּפְדֵּף במילון שוב ושוב. לפעמים הוא שִׁעְמֵם את עצמו בניסוחים שגרתיים — ואז בִּרְבֵּר בקול עד שמצא את המילה הנכונה.

📍 לכל פועל מודגש: זיהוי גזרה (מרובעים) + שורש + שם פעולה.

טקסט ב׳ — סיפור ילדים + כתבה (שאלות 8–14)

הילד נָפַל מהעץ ונָגַשׁ לאמו בוכה. "אל תִּפֹּל שוב!" אמרה. "אם תִּתֵּן לי לטפס לאט, לא אֶפֹּל," השיב. למחרת הוא הִגִּישׁ לה פרח. הממשלה הִגִּישָׁה הצעת חוק — נציג נָפַל בפח והִפִּיל את ההצבעה.
