גזרת השלמים — מה זה?

גזרת השלמים = שורשים שכל שלושת עיצוריהם הם עיצורים "חזקים" — ללא א, ה, ו, י בתוך השורש ומבלי שאחד מהם כפול. זו הגזרה הבסיסית, שממנה לומדים את צורות כל הגזרות האחרות.

דוגמאות: כ-ת-ב, ש-מ-ר, ג-ד-ל, פ-ת-ח, ד-ב-ר, ל-מ-ד, ז-כ-ר.

💡 שלמים = שלמות: כל 3 עיצורי השורש שלמים, אינם גרוניים ואינם כפולים — הצורות "נכנסות" לתבנית ללא שינוי. לכן: גזרת השלמים = הקלה ביותר לנטייה.

בניין נפעל — הסביל של קל
נפ
בניין נפעל — נִפְעַל
Nif'al — Passive / Reflexive
סביל קידומת נ (עבר) / הִנּ (שאר) ניתן גם: חוזר-עצמי
משמעות: סביל — "נעשתה הפעולה לנושא". "נִכְתַּב" = נכתב (ע"י מישהו). גם: חוזר-עצמי: "נִשְׁמַר" = שמר את עצמו.
סימן מזהה בעבר: קידומת נִ לפני פ׳ השורש. "נִ + כ-ת-ב" = "נִכְתַּב".
סימן מזהה בהווה/עתיד/ציווי: קידומת הִנּ (הן + דגש חזק בפ׳). "הִנָּכֵל" / "יִכָּתֵב" (י + כּ בדגש).
שם פעולה: הִקָּטְלוּת — "הִכָּתְבוּת" (נדיר), לרוב: "הִכָּתְבוּת".
נִכְתַּב · נִשְׁמַע · נִפְתַּח · נִגְדַּל · נִלְמַד · נִזְכַּר
כל הזמנים בניין נפעל — שורש כ-ת-ב
זמן / צורה עבר (ג׳ זכר יחיד) הווה עתיד שם פעולה
בסיס נִכְתַּב נִכְתָּב יִכָּתֵב הִכָּתְבוּת
קידומת נִ + שורש נִקְטָל יִ + כּ (דגש) הִ + כּ (דגש)
נקבה רבים נִכְתְּבוּ נִכְתָּבוֹת תִּכָּתַבְנָה —
⚠️ מלכודת — נפעל עבר ↔ נפעל הווה: "נִכְתַּב" (עבר, פתח) לעומת "נִכְתָּב" (הווה, קמץ). ההבדל: תנועת ל׳ השורש. עבר = פתח (נִקְטַל). הווה = קמץ (נִקְטָל).

בניין פיעל — עוצמה ועיסוק
פיע
בניין פיעל — פִּעֵל
Pi'el — Intensive / Causative
פעיל-מחוזק דגש חזק בע׳ השורש מחוזק / עיסוק / שם-פעל
הסימן המובהק: דגש חזק בעי"ן השורש (ע׳ מוכפלת). "דִּבֵּר" = ד + בּ (דגש) + ר. "לִמֵּד" = ל + מּ (דגש) + ד.
משמעויות: (1) עוצמה/ריבוי: "שִׁבֵּר" = שבר שברים רבים. (2) עיסוק/מקצוע: "לִמֵּד" = עסק בלימוד. (3) גרם לאחר: "בִּשֵּׂר" = גרם לשמוע בשורה. (4) שם-פעל: "כִּבֵּד" = כבד (יחס).
שם הפעולה: תבנית קְטִילָה / קִטּוּל — "דִּבּוּר", "לִמּוּד", "כְּתִיבָה".
דִּבֵּר · לִמֵּד · שִׁבֵּר · כִּתֵּב · זִכֵּר · גִּדֵּל
כל הזמנים בניין פיעל — שורש ד-ב-ר
זמן / צורה עבר (ג׳ זכר יחיד) הווה עתיד שם פעולה

רבים דִּבְּרוּ מְדַבְּרִים יְדַבְּרוּ

4 צעדים לזיהוי בניין
📋 איך מזהים בניין במילה?
1
בדוק קידומות: יש נִ לפני הבסיס? → נפעל-עבר. יש מְ? → פיעל הווה / הפעיל הווה. אין? → קל / נפעל הווה / פיעל עבר.
2
בדוק דגש בע׳: יש דגש חזק בעי"ן השורש? → פיעל (או פועל). אין דגש בע׳? → קל / נפעל.
3
בדוק ניקוד: קמץ/פתח בפ׳+ע׳ + אין קידומת? → קל-עבר. נִקְטַל? → נפעל-עבר. פִּעֵל (חיריק+צרה)? → פיעל-עבר.
4
קבע זמן: עבר (סיומת אדם) / הווה (מסכים בגוף+מין) / עתיד (י-ת-נ-א) / שם פעולה (שם עצם).
