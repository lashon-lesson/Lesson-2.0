גזרת השלמים — מה זה ולמה חשוב?

גזרת השלמים = שורשים שכל שלושת עיצוריהם חזקים — ללא א,ה,ו,י בשורש ומבלי שאחד מהם כפול.

דוגמאות: כ-ת-ב, ש-מ-ר, ד-ב-ר, ל-מ-ד, פ-ת-ח, ג-ד-ל, ז-כ-ר, ש-ב-ר

💡 למה ללמוד שלמים ראשון? הצורות בגזרת השלמים = הצורות הטהורות ללא שינויים. כל גזרה אחרת (גרוניים, נחי לי"ה, חסרי פ"נ) = גזרת שלמים + שינויים ספציפיים. שולטים בשלמים — מבינים את כל השינויים.

⚠️ מלכודת — נ כחלק מהשורש?

נִלְמַד — שורש = ל-מ-ד, לא נ-ל-מ! בדיקה: לָמַד (קל) ← אותו שורש. אבל — נָתַן (קל) ← נ = חלק מהשורש נ-ת-נ! ההבחנה: האם הפועל קיים בקל ללא הנ?

בניין פיעל — פִּעֵל
Intensive / Factitive — מחוזק / עיסוק / גרימה
פעילדגש חזק בע׳ תמידמחוזק/עיסוק
משמעות: (א) מחוזק/חוזר: "שִׁבֵּר" = שבר לרסיסים. (ב) עיסוק: "לִמֵּד" = עוסק בהוראה. (ג) גרימה: "כִּבֵּד" = גרם לכבוד.

4 צעדים לזיהוי בניין
📋 איך מזהים בניין?
1
קידומות: נִ לפני פ׳? → נפעל-עבר. מְ? → פיעל-הווה (או הפעיל). אין? → קל / נפעל-הווה / פיעל-עבר.
2
דגש בע׳: דגש חזק בעי"ן? → פיעל (או פועל). אין דגש בע׳? → קל / נפעל.
3
ניקוד יוד בעתיד: יִ + שורש → קל. יִ + פ׳ דגושה → נפעל. יְ (שוא) → פיעל.
4
זמן וגוף: עבר (סיומת) / הווה (בינוני מסכים) / עתיד (י-ת-נ-א + סיומת).

טקסט א׳ — בניין קל (שאלות 1–7)

הוא כָּתַב מכתב ארוך. הם שָׁמְרוּ על הכלים. היא תִּלְמַד לבחינה. אנחנו פָּתַחְנוּ את החלון. אתה זוֹכֵר את הדברים. הן יִגְדְּלוּ מהר.

📍 לכל פועל מודגש: זיהוי זמן, גוף, מין, בניין.

טקסט ב׳ — נפעל ופיעל (שאלות 8–14)

הספר נִכְתַּב בזמן קצר. הדלת נִפְתְּחָה לאט. היא דִּבְּרָה בשקט. הם לִמְּדוּ יחד. הכלב נִשְׁמָר בחצר. יְדַבְּרוּ מחר.

📍 זהו לכל פועל: בניין, זמן, גוף, שורש.
