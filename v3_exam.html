חזרה מהירה — 4×1 כלל מפתח
📏
שם המספר — חוק ההפוך: 1–10: שם עצם זכר ← מספר נקבה (שלושה ספרים). שם עצם נקבה ← מספר זכר (שלוש ילדות). עשרות = ללא שינוי. שלש = שגוי! שלוש/שלושה = נכון.
🔤
אותיות שימוש — 3 שאלות: מה האות? מה אחריה? ב/כ/ל: לפני ה׳ = פתח+דגש (בַּ/כַּ/לַ). לפני שווא = חיריק (בִּ/כִּ/לִ). ו לפני ב/מ/פ = שורוק (וּ). ה לפני גרוני = קמץ (הָ).
📚
כתיב — שאלו 3 שאלות: (1) יש תנועה ארוכה? חולם/שורוק = ו׳. צרי גדול/חיריק גדול = י׳. (2) האות כבר שם? אל תכפלו. (3) מינוח קבוע? בית-ספר, בית-חולים, בן-אדם = מקף.
⏸️
פיסוק — 4 כללים: אבל/אולם = פסיק. לכן/לפיכך = נקודה-פסיק. ציטוט ישיר (":") = מירכאות. ציטוט עקיף ("ש") = ללא מירכאות. פסיק בין נושא לנשוא = שגוי!
⚠️
המלכודות הגדולות: "שמרנו" ✓ (אין חולם → ללא ו׳). "ורנה" ✓ (ו לפני ר = שווא). פסיק לפני "לכן" = שגוי (צריך נ"פ). מירכאות אחרי "אמר ש" = שגוי. "שלש" = שגוי תמיד.

1
זהה: מה השגיאה? מספר / אות שימוש / כתיב / פיסוק? ציין את הצורה השגויה המדויקת.

תקן: מה הצורה הנכונה? כתוב אותה במפורש.
3
הסבר: מדוע? "כי שם עצם [מין] → [כלל]". "כי ב + ה׳ הידיעה = בַּ". "כי לפני לכן = נקודה-פסיק". משפט אחד שלם!
