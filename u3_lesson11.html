דרכי תצורת השם

שפה חיה יוצרת מילים חדשות בכל יום. העברית עושה זאת בשלוש דרכים: שורש ומשקל — המנגנון הוותיק; בסיס וצורן — הדבקת רכיבים; הלחמת בסיסים — שילוב מילים שלמות. שלוש הדרכים פועלות במקביל כיום.

שלוש מילים: מחשב / נגן / טלוויזיה

כולן מילים עבריות מוכרות — אבל כל אחת נוצרה בדרך שונה לחלוטין. האם תוכלו לנחש איך? קראו את השיעור ואז חזרו לכאן.

🔍
1

🔶
2
שורש ומשקל — ה-DNA של העברית

שורש = רצף 3–4 עיצורים הנושא משמעות בסיסית (ח-שׁ-ב = חשיבה). משקל = תבנית תנועות שבתוכה מוכנס השורש — מוסיף משמעות קטגורית: כלי, מקום, מקצוע, תכונה, מופשט.

🔵
3
בסיס וצורן — ניתוח לרכיבים לינאריים

בסיס = צורת המילה שעליה מתבסס הניתוח. צורן = רכיב דקדוקי מינימלי שמוסיפים לפני (קידומת) או אחרי (סיומת) הבסיס. שיטה זו שונה מ"שורש ומשקל" בכך שהיא מנתחת מילים לפי רצף ולא לפי תבנית עם חורים.

🔵 שש דוגמאות — ניתוח בסיס+צורן
לא-קידומת
אפשריבסיס
קידומת שלילה "לא-": לא- + בסיס = שלילת תכונה. "לא-אפשרי", "לא-ידוע", "לא-רשמי". פרודוקטיבי מאוד.
נגןבסיס
-ָןסיומת
סיומת -ָן (בעל מקצוע/תכונה): "נגן+ָן = נַגָּן", "שחק+ָן = שַׂחְקָן", "עצל+ָן = עַצְלָן".
תת-קידומת
קרקעבסיס
קידומת "תת-" (תחת/נמוך): "תת-קרקעי", "תת-תרבות", "תת-ועדה", "תת-אלוף".
בין-קידומת
לאומיבסיס
קידומת "בין-" (ביניים): "בין-לאומי", "בין-עירוני", "בין-תחומי". "בין" = מילה שהפכה צורן.
בריאותבסיס
-איסיומת
סיומת -אי/-אית (מקצוע מודרני): "בריאות+אי", "ספרות+אי = סַפְרוּתַאי", "עיתון+אי = עִיתוֹנַאי".
ביתבסיס
-תיסיומת
סיומת -תי/-י (שייכות/יחס): "בית+תי = בֵּיתִי", "לאום+י = לְאֻמִּי", "ארץ+י = אַרְצִי".
🔵 צורנים לשינון — קידומות: לא-, תת-, בין-, דו-, חד-, רב-, טרום-, אנטי-. סיומות: -ִי/-תִי (שייכות), -ָן/-נִי (תכונה), -אִי (מקצוע מודרני), -וּת (מצב מופשט), -יָּה (מקום/מוסד), -וֹן/-וֹנִי (הקטנה).

6
כיצד לנתח מילה — שלבי הניתוח
🔬 שלוש שאלות לניתוח תצורה
1
האם ניתן לחלץ שורש ולזהות משקל? → שורש+משקל. "מִגְרָשׁ" = ג-ר-שׁ + מִפְעָל.
2
האם יש קידומת/סיומת ניתנת לניתוק? → בסיס+צורן. "לא-ידוע" = לא- + ידוע.
3
האם המילה מורכבת משתי מילים מוכרות? → הלחמה. "כדורגל" = כדור + רגל.
📌 ניתוח שכבתי — "בֵּינְלְאֻמִּי"
שכבה 1: בין- (קידומת) + לאומי (בסיס)
שכבה 2: לאומי = לאום + -י (סיומת שייכות)
שכבה 3: לאום = ל-א-מ + משקל פְּעֻלָּה
= 3 שכבות תצורה מקוננות
📌 ניתוח שכבתי — "כַּדּוּרַגְלָן"
שכבה 1: כדורגל + -ָן (סיומת)
שכבה 2: כדורגל = כדור + רגל (הלחמה)
שכבה 3: כדור = כ-ד-ר + קַטּוּל (שורש+משקל)
= 3 שכבות

5 שאלות לניתוח תצורה
🛠️ 5 שאלות לניתוח דרך התצורה
1
חלץ שורש: הסר תנועות — האם נשארים 3–4 עיצורים עם משמעות? → שורש+משקל.
2
חפש קידומות: לא-, תת-, בין-, דו- בתחילה? → בסיס+צורן קידומת.
3
חפש סיומות: -ָן, -אִי, -וּת, -יָּה בסוף? → בסיס+צורן סיומת.
4
בדוק הלחמה: ניתן לפצל לשתי מילים מוכרות? "כדורגל" ← כדור + רגל.
5
בדוק שכבות: לעתים ניתוח כפול: "בינלאומי" = בין- + לאום (שורש+משקל) + -י (סיומת).

✅ שאלות מנחות לפני התרגול

שאלה 2: "ספורטאי" — מהו הבסיס ומהו הצורן? מה משמעות הצורן?

טקסט א׳ — עולם הטכנולוגיה (שאלות 1–7)

המחשב הנייד הפך לכלי-עבודה עיקרי. המפתח הצעיר עבד על תוכנה חדשה לניהול מסמכים. המערכת הבין-לאומית תומכת בריבוי שפות — כל משתמש יכול לבחור שפת-ממשק נוחה לו.

📍 לכל מילה מודגשת: זיהוי דרך תצורה (שורש+משקל / בסיס+צורן / הלחמה).

טקסט ב׳ — בית-הספר + ספורט (שאלות 8–14)

המחנך הותיק עמד מול כיתת-לימוד מלאה. הוא לא-ידוע ברחוב אך מפורסם בבית-הספר. "אחריות המחנך היא תת-הכרתית." הכדורגלן בחשמלית חשב על אימון — הכרטיסייה שלו מלאה ניקובים.
