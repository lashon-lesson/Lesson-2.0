1
שבע אותיות השימוש — מי הן ומה תפקידן

אותיות השימוש הן אותיות קצרות הנצמדות לתחילת המילה (ולא נכתבות נפרד). הן מחליפות מילות יחס שלמות:

  • בְּ / בִּ — במקום "בתוך" / "על" → "בַּבַּיִת" = "בתוך הבית"
  • כְּ / כִּ — במקום "כמו" / "כפי" → "כַּמּוֹרֶה" = "כמו המורה"
  • לְ / לִ — מייעד, מוסיף על → "לַתַּלְמִיד" = "עבור התלמיד"
  • מִ / מֵ — במקום "מתוך" / "מאת" → "מֵהַבַּיִת" = "מתוך הבית"
  • וְ — חיבור, "וגם" → "סֵפֶר וְעִפָּרוֹן"
  • שֶׁ — מחבר משפטי לוואי → "הילד שֶׁבָּא"
  • הַ — ה׳ הידיעה → "הַסֵּפֶר"

כל אות בנפרד — כלל + ניקוד + שגיאות

בֵּית השימוש

בִּמְהִירוּת, בִּכְלָל

טבלת ניקוד — לפני מה, כמה
אות שימושלפני שם רגיללפני ה׳ הידיעהלפני שוואדגש?
בְּבְּ (שווא)בַּ (פתח)בִּ (חיריק)כן
כְּכְּ (שווא)כַּ (פתח)כִּ (חיריק)כן
לְלְ (שווא)לַ (פתח)לִ (חיריק)כן
מִ/מֵמִ (חיריק)מֵהַ (צרי)מִ (חיריק)—
וְוְ (שווא)וְהַוִ (חיריק)—
שֶׁשֶׁ (סגול)שֶׁהַשֶׁ—
💡 כלל האצבע: ב/כ/ל לפני ה׳ הידיעה = פתח + דגש (בַּ/כַּ/לַ). לפני שווא = חיריק (בִּ/כִּ/לִ). לפני כל שאר = שווא (בְּ/כְּ/לְ).
⚠️
4
שגיאות קלאסיות — מה שחוזר בבגרות
❌ שגיאה 1 — ב+ה׳ הידיעה
כתבתי "בהכיתה" (ב+ה+כיתה נפרדים)
✅ תיקון
"בַּכִּיתָּה"
ב + הכיתה = בַּכִּיתָּה. הה׳ נבלעת ב-בַּ. אין לכתוב "בהכיתה" בניקוד.
❌ שגיאה 2 — לפני שווא
כתבתי "בְּמְהִירוּת" (שווא+שווא)
✅ תיקון
"בִּמְהִירוּת"
כשאות שימוש מגיעה לפני שווא נח — הניקוד הופך לחיריק: בִּ. שני שוואים רצופים = שגוי.
❌ שגיאה 3 — מֵ לפני ה׳
כתבתי "מִהַבַּיִת" (חיריק לפני ה׳)
✅ תיקון
"מֵהַבַּיִת"
מ + הבית = מֵהַ (צרי). לפני ה׳ הידיעה: מֵ (לא מִ). "מִ" = לפני שמות ללא ה׳.
❌ שגיאה 4 — ו׳ לפני ב/מ/פ
כתבתי "וְפֶרַח" (שווא לפני פ׳)
✅ תיקון
"וּפֶרַח"
ו׳ החיבור לפני ב/ו/מ/פ = וּ (שורוק). לפני שפה, ממה, פה — שורוק תמיד.
❌ שגיאה 5 — ה׳ לפני גרוניות
כתבתי "הַאָרֶץ" (פתח לפני א׳)
✅ תיקון
"הָאָרֶץ"
ה׳ הידיעה לפני א/ה/ח/ע/ר = הָ (קמץ). גרוניות אינן מקבלות דגש, והניקוד מתמלא לקמץ.
📄
5
קטע מבגרות — מצאו וְתַקְנּוּ
מתוך חיבור תלמיד — "יום בבית-הספר"
משימת כתיבה, כיתה י׳

בבוקר יצאתי (1)מהבית מוקדם. הלכתי (2)בהרחוב הראשי עד (3)בית-הספר. (4)בכיתה ישבתי ליד חברי (5)ומשה. המורה דיברה (6)כמורה מנוסה (7)ובמהירות הסבירה את החומר.

🔍 פתרון מפורט:

❌ (1) שגוי — "מהבית"
מ + הבית = מהבית
✅ תיקון
מֵהַבַּיִת
מ + ה׳ הידיעה = מֵהַ (צרי). "מהבית" ללא ניקוד מקובל בכתיב חסר, אך עם ניקוד — חייב מֵהַ.
❌ (2) שגוי — "בהרחוב"
ב + הרחוב = בהרחוב
✅ תיקון
בָּרְחוֹב
ב + הרחוב = בַּרְחוֹב (ב+ה׳ → בַּ). הה׳ נבלעת. שימו לב: "ר" גרוניות → הדגש נשמט, הפתח → קמץ: בָּ.
❌ (5) שגוי — "ומשה"
ו + משה = וְמשה
✅ תיקון
וּמשֶׁה
ו׳ לפני מ׳ = וּ (שורוק). "ומשה" עם שווא = שגוי. כלל: לפני ב/ו/מ/פ = שורוק.
❌ (6) שגוי — "כמורה"
כ + מורה = כְּמוֹרֶה? לא בדיוק...
✅ תיקון
תלוי: אם הכוונה "כמו מורה" → כְּמוֹרֶה ✓ | אם "כמו המורה" → כַּמּוֹרֶה
הכוונה "כמו מורה מנוסה" (ללא ה׳ הידיעה) → כְּ ✓. אם הכוונה "כמו המורה" → כַּ.
❌ (7) שגוי — "במהירות"
ב + מהירות → בְּמְהִירוּת (שווא+שווא)
✅ תיקון
בִּמְהִירוּת
ב + מְ (שווא) = בִּ (חיריק). לפני שווא נח — חיריק.
✅ (3) ו-(4) תקינים: "בית-הספר" ✓ (מינוח קבוע). "בכיתה" — בכתיב חסר ניקוד ✓ (בניקוד: בַּכִּיתָּה).
✅
6
שיטת הבדיקה לבגרות — 4 שאלות
📋 לכל אות שימוש — שאלו ברצף
1
מה האות? ב/כ/ל/מ/ו/ש/ה — זהו אותה קודם.
2
מה בא אחריה? ה׳ הידיעה? שווא נח? שם רגיל? גרוני?
3
מה הניקוד הנכון? ב/כ/ל לפני ה׳ = פתח+דגש. לפני שווא = חיריק. לפני רגיל = שווא. ו לפני ב/מ/פ = שורוק.
4
כתבו תשובה מלאה: צורה שגויה → צורה נכונה + הסיבה ("לפני ה׳ הידיעה / לפני שווא / לפני ב/מ/פ").
🔍
7
מלכודות נוספות — לפי שתמיד בוחנות
❌ "ב" נפרדת
בכתיבה: "ב בית" — שגוי!
הנכון: "בַּבַּיִת" (נצמד).
אות שימוש תמיד נצמדת למילה.
❌ כי ≠ כְּ
"אמרתי כי טוב" — כִּי = מחבר משפטים.
"הלך כארי" — כְּ = כמו.
ניקוד שונה = משמעות שונה!
✅ וּבְ / וּמִ
ו לפני ב/מ = וּ:
"וּבְבֵית" = "ובבית"
"וּמִסֵּפֶר" = "ומספר"
שני שוואים לא רצים.
✅ לַמָּה ≠ לָמָּה
לַמָּה = "לשם מה? בשביל מה?"
לָמָּה = "מדוע?" (שאלה)
הניקוד (פתח/קמץ) = ההבדל!
🏆
8
טיפ בגרות — איך לזהות שגיאה מהר
💡 שיטת הסריקה המהירה: בבגרות, חפשו "ב / כ / ל / מ / ו / ש" בתחילת מילה עם ניקוד. שאלו: האות הבאה היא ה׳ הידיעה? שווא? ב/מ/פ? רק שלוש שאלות ותדעו אם יש שגיאה.
⚠️ חשוב: בכתיב חסר ניקוד (כמו בעיתונות) — אותיות השימוש נכתבות מחוברות ללא ניקוד. השגיאות נבדקות בטקסט מנוקד בלבד — אלא אם הבחינה מציינת אחרת.
✅ סיימת את התיאוריה?
✅ מוכנים! ב/כ/ל → שווא/פתח+דגש/חיריק. מ → מִ/מֵהַ. ו → שווא/שורוק. ה → פתח/קמץ לפני גרוניות.
