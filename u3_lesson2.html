מבוא למערכת הצורות

שורש, תבנית, צורן וגזירה — הכלים לפירוק כל מילה עברית ולהבנת בנייתה. תשתית לכל שיעורי הגזרות.

⏱ 45 דק׳ 🔬 מורפולוגיה 🎯 יחידה 3 שיעור 2
🤔 שאלת פתיחה

מה המשותף ל-כָּתַב, כְּתִיבָה, מִכְתָּב, כַּתָּב, כָּתוּב, כּוֹתֵב, הִכְתִּיב, נִכְתַּב?

8 מילים שונות לחלוטין — אבל יסוד אחד משותף. מה הוא? קראו את השיעור ואז תנסחו תשובה מדויקת.

📖
1
מורפולוגיה — מדע בניין המילה

מורפולוגיה (תורת הצורות) = ענף הלשון העוסק בבנייה הפנימית של המילה. בעברית, רוב המילים בנויות על עיקרון אחד:

שורש + תבנית = מילה

הבנת עיקרון זה מאפשרת: ניתוח מילים לא-מוכרות, הסבר תחלופי עיצורים בגזרות, וניתוח מורפולוגי בבגרות.

💡 מורפולוגיה מול תחביר: תחביר = יחסים בין מילים. מורפולוגיה = המבנה הפנימי של המילה. "כָּתַב" — תחביר: פועל/נשוא. מורפולוגיה: שורש כ-ת-ב + תבנית קָטַל + בניין קל + עבר ג׳ ז׳ י׳.
🌳
2
השורש — לב המילה

שורש = רצף עיצורים (לרוב 3, לעיתים 4) הנושא משמעות בסיסית. השורש עצמו אינו מילה — הוא מבנה אבסטרקטי שמניב מילים בהצטרפו לתבנית.

3
התבנית (המשקל) — מסגרת המילה

תבנית (משקל) = המסגרת שאליה נכנס השורש. היא קובעת את ניקוד המילה, תפקידה הדקדוקי ומשמעותה הכללית. מסמנים אותה לפי עיצורי פ-ע-ל: פ = ראשון, ע = שני, ל = שלישי.

5
צורנים — הרכיבים הנוספים

צורן (מורפמה) = יחידת משמעות מינימלית שאינה ניתנת לחלוקה נוספת. כל מילה = צורן אחד או יותר.

📋 סוגי צורנים
סוגהגדרהדוגמאות
חופשי (בסיס)עומד לבד כמילהשָׁלוֹם, בַּיִת, יֶלֶד
קשורחייב להצטרף לאחרמְ-, -וּת, -ָה, -יִם
קידומת (פרפיקס)לפני הבסיסמְדַבֵּר (מְ-), הִכְתִּיב (הִ-), נִכְתַּב (נִ-)
סיומת (סופיקס)אחרי הבסיסגְּדוֹלָה (-ָה), אַחְדוּת (-וּת), עִתּוֹן (-וֹן)
⚠️ מלכודות נפוצות
  • ה"א בתחילת מילה: "הִכְתִּיב" — הִ = קידומת. "הַבַּיִת" — הַ = ה"א הידיעה. לא חלק מהשורש!
  • נ"ון בתחילה: "נִכְתַּב" — נִ = קידומת נפעל. לא חלק מהשורש כ-ת-ב.
  • מ"ם בתחילה: "מִכְתָּב" — מִ = חלק מהתבנית מִקְטָל. לא שורש מ-כ-ת.
🔄
6
גזירה — מניין מגיעות המילים?

גזירה = תהליך יצירת מילה חדשה ממילה/שורש קיים. שלושה מסלולים עיקריים:

🔄 שלושת מסלולי הגזירה
מסלולתהליךדוגמה
1 — מן השורששורש + תבנית → מילה ישירותד-ב-ר + מִקְטָל → מִדְבָּר
2 — משם (שורש תנאי)שם קיים → שורש מלאכותי → פועלטֵלֵפוֹן → ט-ל-פ → טִלְפֵּן
3 — הרכבה / לחםשתי מילים → מילה חדשהבֵּית + סֵפֶר → בֵּית-סֵפֶר
ד-ב-ר ← דִּבֵּר ← דִּבּוּר ← מְדַבֵּר ← מְדַבְּרִים מסלול גזירה: שורש → פיעל עבר → שם פעולה → בינוני → רבים
✅ כלל הגזירה משם: האקדמיה ללשון העברית מאשרת שורשים שנוצרו משמות זרים. "טִלְפֵּן" (← טֵלֵפוֹן), "פַּקְסֵס" (← פַּקְס), "מִחְשֵׁב" (← מַחְשֵׁב) — תקניים לחלוטין.
📊
7
סיכום — 5 צעדים לניתוח מורפולוגי
📋 כיצד מנתחים מילה?
1
הפרד קידומות וסיומות: "מְדַבֵּר" → מְ (קידומת) + דַבֵּר (בסיס)
2
זהה שורש: 3/4 העיצורים הנושאים משמעות. "מְדַבֵּר" → ד-ב-ר
3
זהה תבנית: החלף בפ-ע-ל. "מְדַבֵּר" → מְפַעֵל = בינוני פיעל
4
זהה בניין: על בסיס תבנית + קידומות. מְקַטֵּל = פיעל. הִקְטִיל = הפעיל.
5
הסק משמעות: שורש + תבנית + בניין. "מְדַבֵּר" = עושה פעולת דיבור, הווה, פיעל.
