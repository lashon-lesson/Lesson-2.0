1
מהי מורפולוגיה?

מורפולוגיה (תורת הצורות / מערכת הצורות) היא ענף הלשון העוסק בבניין המילה — כיצד מילים נוצרות, כיצד הן מוטות, ומה מרכיביהן. בעברית, מרבית המילים בנויות לפי עיקרון אחד:

שורש + תבנית = מילה

הבנת המבנה הזה מאפשרת: ניתוח מילים לא-מוכרות, הגדרת שורשים, הסבר הכפלות ותחלופים, וניתוח מורפולוגי בבגרות.

💡 הבדל מתחביר: תחביר = יחסים בין מילים במשפט. מורפולוגיה = המבנה הפנימי של המילה עצמה. "כָּתַב" — תחביר: פועל, נשוא. מורפולוגיה: שורש כ-ת-ב, תבנית קָטַל, בניין קל, עבר, גוף ג׳ זכר יחיד.
🌳
2
השורש — לב המילה

שורש הוא רצף של עיצורים (לרוב 3, לפעמים 4) הנושא את המשמעות הבסיסית. השורש עצמו אינו מילה — הוא מבנה אבסטרקטי שמניב מילים בהצטרפו לתבנית.

מאפיינים:

  • לרוב 3 עיצורים (תלת-עיצורי): כ-ת-ב, ה-ל-כ, ד-ב-ר
  • לפעמים 4 עיצורים (מרובע): ת-ר-ג-ם, צ-פ-צ-פ
  • עיצורים חלשים (א, ה, ו, י) — גורמים לחילופי עיצורים בגזרות
  • השורש = אוסף המשמעויות — כ-ת-ב = כל הקשור לכתיבה
🔬 ניתוח שורש — מה מניב השורש כ-ת-ב
כָּתַב כָּתוּב כְּתִיבָה כַּתָּב מִכְתָּב כְּתוֹבֶת הִכְתִּיב נִכְתַּב
שורש: כ-ת-ב כולן = קשורות לכתיבה 8 מילים שונות, שורש אחד
🧩
3
התבנית (המשקל) — מסגרת המילה

תבנית (משקל) = המסגרת שאליה נכנס השורש. היא קובעת את ניקוד המילה, תפקידה הדקדוקי ומשמעותה הכללית. מסמנים אותה לפי עיצורי פ-ע-ל (פ = עיצור ראשון, ע = שני, ל = שלישי).

תבנית (פ-ע-ל) משמעות כללית דוגמה עם כ-ת-ב דוגמה עם ד-ב-ר
קָטַלפועל עבר קל, גוף ג׳ זכרכָּתַבדִּבֵּר (פיעל)
קְטִילָהשם פעולה — קטגוריה/פעולהכְּתִיבָהדִּבּוּר
מִקְטָלשם מקום / שם פעולהמִכְתָּבמִדְבָּר
קַטָּלשם מקצוע / בעל מידהכַּתָּבדַּבָּר
קָטוּלבינוני פעול — "מְקוּטָל"כָּתוּבדָּבוּר
קוֹטֵלבינוני פועל — "הָעוֹשֶׂה"כּוֹתֵבמְדַבֵּר
⚠️ חשוב: אותה תבנית + שורשים שונים = מילים שונות באותו מבנה. "כַּתָּב" (כ-ת-ב) ו"נַגָּר" (נ-ג-ר) — שניהם במשקל קַטָּל = בעלי מקצוע.
🔬
4
ניתוח מילה — פ-ע-ל בפועל
🔬 ניתוח: "מְדַבֵּר"
מְדַבֵּר
מְ קידומת
דַ פ׳ השורש
בֵּ ע׳ השורש
ר ל׳ השורש
שורש: ד-ב-ר תבנית: מְקַטֵּל קידומת: מְ (בניין פיעל, הווה) דגש חזק בב׳ = ע׳ מוכפלת = פיעל
🔬 ניתוח: "כְּתִיבָה"
כְּתִיבָה
כְּ פ׳ השורש
תִ ע׳ השורש
י אות תבנית
בָ ל׳ השורש
ה סיומת נקבה
שורש: כ-ת-ב תבנית: קְטִילָה סיומת: ה (שם עצם נקבה) שם פעולה של בניין קל
🧱
5
צורנים — הרכיבים הנוספים

צורן (מורפמה) = יחידת משמעות מינימלית שאינה ניתנת לחלוקה נוספת. כל מילה מורכבת מצורנים.

סוגי צורנים:

  • צורן חופשי (בסיס): יכול לעמוד לבד כמילה. "שָׁלוֹם", "בֵּית"
  • צורן קשור: אינו עומד לבד — חייב להצטרף. "מְ-", "-ָה", "-וּת"
  • קידומת (פרפיקס): צורן לפני הבסיס. "מְדַבֵּר" — מְ + דַבֵּר
  • סיומת (סופיקס): צורן אחרי הבסיס. "גְּדוֹלָה" — גְּדוֹל + ָה
  • תחילית (אינפיקס): צורן בתוך הבסיס — נדיר בעברית
קידומות נפוצות
מְ- = בינוני פועל, שם פעולה בפיעל
הִ- = עבר הפעיל / התפעל
נִ- = עבר נפעל
תְ- = עתיד / נקבה
יְ- = עתיד זכר
סיומות נפוצות
-ָה = נקבה יחיד ("גְּדוֹלָה")
-וּת = שם עצם מופשט ("אַחְדוּת")
-וֹן = שם עצם ("עִתּוֹן")
-יִם = זכר רבים
-וֹת = נקבה רבים
🔄
6
גזירה — מניין מגיעות המילים?

גזירה = תהליך יצירת מילה חדשה ממילה קיימת. בעברית יש שלושה מסלולי גזירה עיקריים:

1️⃣ גזירה מן השורש
שורש + תבנית → מילה. הדרך הרגילה: ד-ב-ר + קָטַל → דִּבֵּר. כ-ת-ב + מִקְטָל → מִכְתָּב. המילה נגזרת ישירות מן השורש.
2️⃣ גזירה משם (שורשים תניינים)
שם עצם קיים → פועל נגזר. "טֵלֵפוֹן" → טִלְפֵּן. "כַּדּוּר" → כִּדֵּר. "אוֹטוֹבּוּס" → אֹטֵּב. השורש נוצר רטרואקטיבית.
3️⃣ הרכבה ולחם
שתי מילים + חיבור → מילה חדשה. "בֵּית + סֵפֶר" → בֵּית-סֵפֶר. "רַכֶּבֶת + תַּחְתִּית" → רַכֶּבֶת-תַּחְתִּית. לעיתים: הלחם = "מַדְעִים" ← "מַדָּע + מִדְעִים".
📊
7
סיכום — הכלים לניתוח מילה
מושג הגדרה דוגמה
שורשרצף עיצורים נושא משמעות בסיסיתכ-ת-ב, ד-ב-ר, ה-ל-כ
תבנית / משקלמסגרת ניקוד הקובעת תפקיד + משמעותקָטַל, מִקְטָל, קַטָּל
צורןיחידת משמעות מינימליתמְ-, -וּת, -ָה, -יִם
קידומתצורן לפני הבסיסמְדַבֵּר, הִכְתִּיב, נִכְתַּב
סיומתצורן אחרי הבסיסגְּדוֹלָה, אַחְדוּת
גזירהתהליך יצירת מילה חדשהד-ב-ר → דִּבֵּר → דִּבּוּר → מְדַבֵּר
📋
8
5 צעדים לניתוח מורפולוגי
📋 איך מנתחים מילה?
1
הפרד קידומות וסיומות: "מְדַבֵּר" — מְ (קידומת) + דַבֵּר (בסיס)
2
זהה את השורש: 3 (או 4) העיצורים הנושאים משמעות. "מְדַבֵּר" → ד-ב-ר
3
זהה את התבנית: החלף בפ-ע-ל. "מְדַבֵּר" → מְפַעֵל = בינוני פועל פיעל
4
זהה בניין: על בסיס התבנית + קידומות. מְקַטֵּל = פיעל. מִקְטָל = הפעיל.
5
הסק משמעות: שורש + תבנית + בניין → מה המילה מבטאת? "מְדַבֵּר" = עושה פעולת דיבור, הווה.
