מפת כל הגזרות — פריסה שלמה

יחידה ב׳ כיסתה 9 גזרות (+ שלמים כבסיס). כל גזרה מוגדרת על-פי איזה עיצור חלש ובאיזה מיקום:

✅ שלמים
אין עיצורים חלשים — הנטייה "הרגילה"
כ-ת-ב, ש-מ-ר, ל-מ-ד → כָּתַב, יִכְתֹּב, הִכְתִּיב
🔊 גרוניים
א/ה/ח/ע בפ״ש, ע״ש או ל״ש → אין דגש חזק; חטף במקום שווא; פתח גנוב בסוף
ע-מ-ד, ב-ח-ר, ש-ל-ח → יַעֲמֹד, בָּחַר, שָׁלַחַ
🔷 פ״נ
נ׳ בפ״ש → נשמטת בקל עתיד+ציווי + בהפעיל (תמיד); דגש חזק פיצוי
נ-פ-ל → נָפַל / יִפֹּל / הִפִּיל
🟢 פ״י
י׳ בפ״ש → נשמטת רק בקל (עתיד: יֵ+צרי); בבניינים אחרים: י→ו
י-ש-ב → יָשַׁב / יֵשֵׁב / הוֹשִׁיב
🌸 ל״ה
ה׳ בל״ש → עבר=הָ; הווה/עתיד=ֶה; ציווי=ֵה; שפ"ל פיעל=וּי; הפעיל=יָה
ב-נ-ה → בָּנָה / יִבְנֶה / גִּלּוּי / הַטָּיָה
☀️ ע״ו
ו׳ בע״ש → קל עבר: חד-הברי; עתיד: יָ+שורוק; הפעיל: הֵ+חיריק
ק-ו-מ → קָם / יָקוּם / הֵקִים
💧 ע״י
י׳ בע״ש → קל עבר: חד-הברי; עתיד: יָ+חיריק; הפעיל: הֵ+חיריק
ש-י-ר → שָׁר / יָשִׁיר / הֵשִׁיר
💎 כפולים
ע״ש=ל״ש → 2 צורות (כבדה/קלה) בקל; הפעיל: הֵ+צרי שני; שפ"ל פיעל=סִבּוּב
ס-ב-ב → סָב/סָבַב / יָסֹב/יִסְבֹּב / הֵסֵב
🏗️ מרובעים
4 עיצורים → 3 בניינים בלבד (פיעלל/פועלל/התפעלל); שפ"ל: פַּעְלוּל
ת-ר-ג-מ → תִּרְגֵּם / מְתַרְגֵּם / תַּרְגּוּם
🔮 מורכבים
2+ עיצורים חלשים → ציין את כל הגזרות! החל כל כלל בנפרד
נ-ט-ה (פ״נ+ל״ה) → יִטֶּה / הִטָּה | ה-י-ה (גרוני+ע״י+ל״ה) → יִהְיֶה

8 אסטרטגיות בגרות — מה עושים בבחינה
אסטרטגיה 1
ספרו עיצורים קודם
לפני כל ניתוח — ספרו כמה עיצורים בשורש. 2 נראים → חד-הברי (ע״ו/ע״י/כפולים). 4 → מרובעים. 3 → כל השאר.
אסטרטגיה 2
הניקוד קובע הכל
קָ (קמץ) = עבר. ֶה = הווה/עתיד ל״ה. הֵ+חיריק = הפעיל ע״ו. הֵ+צרי = כפולים. הניקוד אחרי מ׳ → קבע הבניין.
אסטרטגיה 3
תִּ = שתי אפשרויות
תִּ בעתיד = ג׳ נקבה יחיד (היא) OR ב׳ זכר יחיד (אתה). תמיד ציינו שתיהן אם אין הקשר!
אסטרטגיה 4
מורכב = ציינו הכל
נ-ט-ה → "פ״נ + ל״ה". ה-י-ה → "גרוני + ע״י + ל״ה". ניתוח חסר גזרה = נקודות חסרות.
אסטרטגיה 5
שם פעולה = בונוס
כשנשאל שם פעולה — זכרו: פועל+הופעל = אין. פיעל ל״ה = וּי. הפעיל ל״ה = יָה. מרובעים = פַּעְלוּל.
אסטרטגיה 6
דגש אחרי יִ = זיהוי
יִ + דגש + קמץ+צרי = נפעל. יִ + דגש + חולם = פ״נ קל. יִי + דגש = נפעל ע״ו. הדגש + ניקוד שאחריו = המפתח.
אסטרטגיה 7
ציווי = זמן, לא גוף
ציווי הוא הזמן; גוף ציווי = תמיד ב׳ (שני). שיעור 10 הדגיש: "בניין X, ציווי, ב׳ יחיד/רבים זכר/נקבה".
אסטרטגיה 8
שחזרו את השורש
כשלא בטוחים בשורש — כתבו את הצורה בלי תחיליות וסיומות. מה נשאר? אלה עיצורי השורש.

חרוז זיכרון — כל הגזרות בסדר
🎵 שיר הגזרות — לשנן לפני הבגרות
שְׁלֵמִים בְּלִי בְּעָיָה, / שלמים — הכל רגיל
גְּרוֹנִי בְּלִי דַּגֵּשׁ בְּגוּפָיָה, / גרוני — ללא דגש
פ״נ — נוּן נוֹשֶׁרֶת מִן הַנְּוָיָה, / פ״נ — נ נשמטת
פ״י — יוֹד נֶעֱלֶמֶת, רַק בְּקַל הִיא מוּסָיָה, / פ״י — בקל בלבד
לָמֶ"ד-הֵ — הֵ מִשְׁתַּנָּה לְפִי הַזְּמַן וְהַגָּוָה, / ל״ה — עבר/עתיד/הווה
עַיִ"ן-וָ"ו — בְּאֶמְצַע שׁוּרוּק, בְּעָתִיד קוּמָה מְגוּיָה, / ע״ו — שורוק
עַיִ"ן-יוֹד — חִירִיק חֲלִיפָה, שִׁיר בְּחִינָּה, / ע״י — חיריק
כְּפוּלִים — שְׁתֵּי צוּרוֹת, כְּבֵדָה וְקַלָּה מְשׁוּנָה, / כפולים — 2 צורות
מְרוּבָּעִים — אַרְבָּעָה, שְׁלֹשָׁה בִּנְיָנִים — שִׁינּוּי! / מרובעים — 3 בניינים

5
שמות פעולה — טבלת מפתח מהירה
קל שלמים = כְּתִיבָה קל ל״ה = בְּנִיָּה קל פ״נ = נְפִילָה קל ע״ו = קִימָה
פיעל = כִּתּוּב פיעל ל״ה = גִּלּוּי פיעל מרובעים = תַּרְגּוּם פועל = אין!
הפעיל = הַכְתָּבָה הפעיל ל״ה = הַטָּיָה הפעיל פ״נ = הַפָּלָה הפעיל ע״ו = הֲקָמָה
הופעל = אין! התפעל = הִתְכַּתְּבוּת התפעל ל״ה = הִתְגַּלּוּת נפעל = הִיכָּתְבוּת
⚠️ כלל הזהב לשמות פעולה: פֻּעַל + הֻפְעַל = אין שם פעולה. לשאר — יש. פיעל ל״ה = י׳ בסוף (לא ה׳). הפעיל ל״ה = יָה בסוף (לא אָה, אלא אם ל״א).
🔬
6
נקודות דיוק — מה לוקחים נקודות
✏️
הסתמי עם שתי אפשרויות: תִּ בעתיד = ציינו "ג׳ יחיד נקבה (היא) או ב׳ יחיד זכר (אתה)". שתי ג׳ נקבה ב׳ זכר = מקבלים נקודה מלאה.
✏️
שורש מורכב = כתבו שתי גזרות: "גזרת פ״נ + ל״ה". אפילו אם זיהיתם נכון — ניסוח "ל״ה בלבד" = ניקוי חלקי.
✏️
ציווי = זמן, לא גוף: "בניין X, ציווי, ב׳ יחיד זכר". לא לכתוב "עתיד" במקום "ציווי".
✏️
שם פעולה מבוקש — תמיד ציינו: אם נשאל שם פעולה לפועל+הופעל — כיתבו "אין שם פעולה לבניין זה". לא לדלג!
✏️
שמות פעולה ל״ה: "גִּלּוּי" (פיעל, לא גִּלּוּה). "הַטָּיָה" (הפעיל, לא הַטָּאָה). "רְאִיָּה" (קל ר-א-ה).

8
ברכה לדרך — לפני הבגרות
🌟 לפני הבגרות — 3 עקרונות
1. ספרו לפני שאתם ניתחים: עיצורים קודם, בניין שני, גזרה שלישית. הסדר מונע טעויות.
2. הניקוד הוא חברכם: קמץ = עבר. סגול-ה = הווה/עתיד. הֵ+חיריק = ע״ו הפעיל. הֵ+צרי = כפולים. אל תנחשו — קראו את הניקוד.
3. כתבו שתי אפשרויות כשיש ספק: "ג׳ נקבה / ב׳ זכר" — לא מפסידים נקודות, ואולי מרוויחים.
