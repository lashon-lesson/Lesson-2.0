כתיב חסר ומלא — זיהוי ותיקון שגיאות

כתיב ללא ניקוד — איך כותבים נכון כשאין תנועות? מתי כותבים אות שימוש ומתי לא? שיעור זה מלמד את הכללים, המלכודות והשגיאות שחוזרות בכל בגרות 70%

⏱ 45 דק׳ 📘 תקינות 70% 📚 כתיב חסר ומלא 📍 שיעור 3 מתוך 4 ביחידה ג׳
💭 שאלת פתיחה — מה נכון?

שלוש גרסאות — רק אחת תקנית לחלוטין:
א. "הוא לומד בביה"ס ומגיע כל יום ברגל."
ב. "הוא לומד בבית-ספר ומגיע כל יום ברגל."
ג. "הוא לומד בבית הספר ומגיע כל יום ברגל."

💡 ב׳ ו-ג׳ שתיהן מקובלות. "ביה"ס" = ראשי תיבות (לא כתיב חסר). השאלה האמיתית: האם "יום" מנוקד? ללא ניקוד — "יום" ✓. אבל האם יש מקרים שצריך אות ייצוג נוספת? כן — ובזה עוסק שיעור זה.

📖
1
כתיב חסר ומלא — הרעיון הבסיסי

כתיב מלא = כתיבה ללא ניקוד שבה תנועות ארוכות (חולם, שורוק, צרי, חיריק) מיוצגות באותיות: ו, י (אמות קריאה).

כתיב חסר = כתיבה שבה אמות הקריאה נשמטות — בדרך כלל בטקסטים מנוקדים. בכתיב ללא ניקוד — הכתיב המלא חובה ברוב המקרים.

בבגרות 70% שואלים לרוב על כתיב ללא ניקוד — האם נכתבה אות ייצוג כשנדרשת, ואם נכתבה אות ייצוג כשלא נדרשת.

וֹ
2
וָ"ו כאות ייצוג — חולם ושורוק
🔵
ו׳ מייצגת שתי תנועות שונות
חולם (וֹ) = ייצוג חובה | שורוק (וּ) = ייצוג חובה
חולם (וֹ) — ניקוד: נקודה על הו׳
תוֹם → תום ✓
יוֹם → יום ✓
שוֹמֵר → שומר ✓
מוֹרֶה → מורה ✓
שורוק (וּ) — ניקוד: נקודה בתוך הו׳
קוּם → קום ✓
שוּב → שוב ✓
חוּץ → חוץ ✓
רוּחַ → רוח ✓
❌ שגיאה נפוצה: "שמר" (ללא ו׳) במקום "שומר". "רח" במקום "רוח". כשיש חולם/שורוק — הו׳ חובה בכתיב ללא ניקוד!
יִ
3
יוֹ"ד כאות ייצוג — צרי וחיריק
🟢
י׳ מייצגת שתי תנועות
צרי (ֵי) = ייצוג חובה | חיריק גדול (ִי) = ייצוג חובה
צרי (ֵי) — שתי נקודות + יו"ד
בֵּית → בית ✓
אֵיךְ → איך ✓
מֵי → מי ✓
שֵׁם → שם (צרי ללא יו"ד — ראה הסבר)
חיריק גדול (ִי) — נקודה + יו"ד
שִׁיר → שיר ✓
כִּיתָה → כיתה ✓
גִּיבּוֹר → גיבור ✓
בִּיאָה → ביאה ✓
⚠️ צרי קטן ≠ צרי גדול: שֵׁם (צרי ללא יו"ד) → שם ✓ (ללא י׳). אבל מֵיטִיב (צרי + יו"ד) → מיטיב ✓ (עם י׳). ההבדל: האם הניקוד מגיע עם יו"ד או בלעדיה.

כללים מיוחדים — יוצאים מהכלל
כללדוגמה מנוקדתכתיב תקני ללא ניקודהסבר
צרי ללא יו"דשֵׁם, בֵּן, עֵץשם, בן, עץצרי קטן (ללא י׳ בניקוד) → ללא י׳ בכתיב
חיריק קטןבִּלְתִּי, מִדְרָשׁבלתי, מדרשחיריק קטן (ללא י׳ בניקוד) → ללא י׳ בכתיב
חולם חסרכֹּל, תֹּרָהכל, תורהכֹּל = ללא ו׳. תוֹרָה = עם ו׳. שימו לב להבדל!

6
5 שגיאות שחוזרות בבגרות
❌ שגיאה 1 — הסרת ו׳ חולם
כתב: "שמר על ילד קטן" (ללא ו׳)
✅ תיקון
"שומר על ילד קטן"
שוֹמֵר — ו׳ חולם חובה בכתיב ללא ניקוד. ללא ו׳ → קורא יקרא "שמר" (עבר)!
❌ שגיאה 2 — כפילות ו׳
כתב: "כותוב" (ו׳ כפולה)
✅ תיקון
"כותב"
כּוֹתֵב — ו׳ אחת בלבד. הצרי (ֵ) אחרי כּ לא מיוצג בו׳ כאן (צרי ללא יו"ד).
❌ שגיאה 3 — הסרת י׳ חיריק גדול
כתב: "הלך לכתה" (ללא י׳)
✅ תיקון
"הלך לכיתה"
כִּיתָה — חיריק גדול (עם יו"ד בניקוד) → י׳ חובה בכתיב ללא ניקוד.
❌ שגיאה 4 — "בית ספר" ללא מקף
כתב: "בית ספר" (שני מרכיבים נפרדים)
✅ תיקון
"בית-ספר"
מינוחים קבועים כתוב עם מקף. כך גם: מגן-דוד, בן-אדם, בית-חולים, תל-אביב.
❌ שגיאה 5 — י׳ מיותרת בצרי קטן
כתב: "יש לו שיֵם יפה" (י׳ מיותרת)
✅ תיקון
"יש לו שם יפה"
שֵׁם = צרי קטן (ללא י׳). לכן בכתיב = שם (ללא י׳). לא "שיֵם" ולא "שיים".
📄
7
קטע מבגרות — מצאו וְתַקְנּוּ
תיאור נסיעה — כתיבה חופשית
תלמיד כיתה י׳, מטלת בית

בחופש הגדול נסעתי עם (1)המשפחה שלי לצפון הארץ. ביקרנו ב(2)בית ספר ישן שהפך למוזיאון, ואחר כך ירדנו לנהר (3)הירדן. (4)שמרנו על הציוד בזהירות. לקראת הערב ישבנו ל(5)אכילה ועשינו (6)שיחה נעימה על מה שראינו. (7)אחכה בציפייה לחופש הבא.

🔍 פתרון מפורט:

❌ (2) שגוי — "בית ספר"
מינוח קבוע ללא מקף
✅ תיקון
"בית-ספר"
מינוחים קבועים (תמידות לשוניות) נכתבים עם מקף: בית-ספר, בית-חולים, בן-אדם.
❌ (4) שגוי — "שמרנו"
"שמרנו" — חסרה ו׳?
✅ תיקון
"שמרנו" ← תקין!
שָׁמַרְנוּ — ניקוד: שָׁ (קמץ), מַ (פתח), רְ, נוּ. אין חולם ואין שורוק לפני נו׳. לכן ללא ו׳ = נכון!
❌ (7) בדיקה — "אחכה"
"אחכה" — האם חסרה ו׳?
✅ תיקון
"אחכה" ← תקין!
אֲחַכֶּה — פתח, לא חולם. אין צורך בו׳. "אחכה" = נכון. "אחוכה" = שגוי.
✅ (1), (3), (5), (6) תקינים: "המשפחה שלי" ✓. "הירדן" ✓. "אכילה" ✓ (אֲכִילָה, י׳ קיימת). "שיחה" ✓ (שִׂיחָה, י׳ חיריק גדול).

⚠️ מלכודת: "שמרנו" — תלמידים רבים יוסיפו ו׳ בטעות. אין כאן חולם!
✅
8
שיטת הבדיקה + מינוחים קבועים
📋 3 שאלות לכל מילה חשודה
1
האם יש תנועה ארוכה? חולם/שורוק → ו׳. צרי גדול/חיריק גדול → י׳. אם אין — אין אות ייצוג.
2
האם אות הייצוג כבר קיימת? "כותב" כבר יש ו׳. "שיר" כבר יש י׳. אל תכפילו!
3
האם זה מינוח קבוע? בית-ספר, בית-חולים, בן-אדם, מגן-דוד — עם מקף תמיד.
מינוחים עם מקף
בית-ספר, בית-חולים
בית-כנסת, בית-סוהר
בן-אדם, בת-מצווה
מגן-דוד, תל-אביב
שגיאות תכופות
שמר ← שומר
כתה ← כיתה
בית ספר ← בית-ספר
כותוב ← כותב
✅ סיימת את התיאוריה?
✅ מוכנים! חולם/שורוק = ו׳. צרי גדול/חיריק גדול = י׳. צרי קטן/חיריק קטן = ללא אות. מינוחים קבועים = מקף.
