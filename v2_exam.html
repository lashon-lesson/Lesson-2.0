📋 הוראות המבחן
1 שאלות 1–10: זיהוי בניין וגזרה — שאלות רב-בחירה מגוונות מכל הגזרות.

4 שאלות 23–25: כתיבה פתוחה — ניתוח מפורט, שמות פעולה, כתיבת צורות.

חזרה מהירה — 6 כללי מפתח
🔑
הניקוד קובע הכל בהווה: מַ = הפעיל. מְ + פתח = פיעל. מְ + קיבוץ = פועל. מֻ = הופעל. מִתְ = התפעל. יִ + דגש + קמץ + צרי = נפעל עתיד.
🔢
ספרו עיצורים תחילה: 2 נראים → ע״ו / ע״י / כפולים. 4 → מרובעים. 3 → כל השאר. דגש פיצוי אחרי יִ → פ״נ נשמטה.
🌸
ל״ה — הה׳ מתחלפת לפי זמן: קמץ-ה (הָ) = עבר. סגול-ה (ֶה) = הווה/עתיד. צרי-ה (ֵה) = ציווי. שם פעולה: פיעל = גִּלּוּי (וּי). הפעיל = הַטָּיָה (יָה, לא אָה!).
☀️
ע״ו / ע״י / כפולים — הפעיל: הֵ + חיריק = ע״ו (הֵקִים). הֵ + צרי שני = כפולים (הֵסֵב). עתיד קל: שורוק = ע״ו (יָקוּם). חיריק = ע״י (יָשִׁיר).
🔮
מורכבים — ציין את כולן: נ-ט-ה = פ״נ + ל״ה ← יִטֶּה, הִטָּה. ה-י-ה = גרוני + ע״י + ל״ה ← יִהְיֶה. כמה גזרות = כמה מנגנונים. ניתוח חסר גזרה = ניקוד חסר!
⚠️
מלכודות בגרות: תִּ בעתיד = ב׳ זכר או ג׳ נקבה — ציין שתיהן! פֻּעַל + הֻפְעַל = אין שם פעולה. ציווי = זמן (גוף ציווי = ב׳ תמיד).

שאל/י לפני שעונה — 3 שאלות אבחון
📋 סדר הניתוח — תמיד באותו סדר
1
ספרו עיצורים: הסר תחיליות (הִ/מַ/יִ) וסיומות (תָּ/וּ). כמה עיצורים נשארו? 2 = ע״ו/ע״י/כפולים. 4 = מרובעים. 3 = כל השאר.
2
קבע בניין: מַ=הפעיל, מְ+פתח=פיעל, מְ+קיבוץ=פועל, מֻ=הופעל, מִתְ=התפעל. הווה = מ׳ תמיד. הִ+שורש=הפעיל. יִ+דגש+קמץ=נפעל.
3
זהה גזרה: האם יש עיצור חלש? נ/י בפ״ש, ה בל״ש, ו/י בע״ש, ע״ש=ל״ש. שורש מורכב = ציין את כל הגזרות.
4
קבע זמן + גוף: יִ/תִּ/אֶ = עתיד. קמץ ראשון = עבר. מ׳ = הווה. סיומת תָּ/תְּ/תֶּם = עבר ב׳. תִּ בעתיד = ב׳ זכר או ג׳ נקבה!
💡 טיפ לפני המבחן: שורש מורכב → ציין הכל: "גזרת פ״נ + ל״ה". ציוויי = זמן, הגוף = ב׳ תמיד. פֻּעַל / הֻפְעַל = אין שם פעולה. הפעיל ל״ה = יָה (לא אָה!)
